# 01 · 产品范围

首版服务于在自己电脑上制作动态表单的配置者。作者能够给 Agent 一段需求，拿到一份可检查的候选定义，然后查看差异、可视化调整、试填并保存到本机。

## 第一条业务路径

1. 新建旅险工作区，输入两名被保人的字段、出行起止日期和姓名规则。
2. Agent 列出缺失条件，或者生成候选：布局用日期范围物料，姓名约束调用 `text.isNonBlank`。
3. 查看 Compiler 诊断和候选差异。人工应用后，在画布修改提示文字，用 JSON 核对并撤销。
4. 用两位成员试填，分别验证一位成员姓名为空白、另一位填写有效时的结果归属。
5. 保存定义，关闭并重新打开桌面应用，核对版本和工作稿。

| 运行形态 | 首版行为 |
| --- | --- |
| 无网络 | 本机编辑、编译、预览、保存和打开已有项目。无法连接模型时保留输入，允许手工继续。 |
| 配置模型后 | Pi 在本机调用获准模型。模型可以在远端；外发内容依据模型配置和当前任务范围。 |
| 可选的遥测 | 用户配置并启用后上报脱敏的轮次与工具指标。关闭或无法连接时依然可以工作。 |

团队权限、云端同步、在线 Release 分发、本地模型安装管理和无人值守自动改写不进入首版。工作台首批以一个真实旅险场景验收，复杂能力按引擎契约逐步接入。
