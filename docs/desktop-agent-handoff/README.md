# 端侧表单 Agent · 新项目交接包

这份规划草案供独立桌面项目交接使用。拟议工具沿用 Assemble Studio 的引擎分层和编辑语义，通过 Electron、React、Pi Agent 和 Langfuse 组织本地创作、试填与观测。兼容性、打包和真实模型验收仍待新项目验证。

**用于规划的默认选择**是先做 macOS 单用户版本，Agent 进程、编译、预览和保存运行在本机。真实生成先连接用户配置的模型服务，支持断网打开、编辑、检查和保存；离线推理等待本地模型验证。Langfuse 首发作为可关闭的遥测接入。本地存储、模型供应商、制品分发方式都在首批验证中落定。更改这些假设时先更新对应章节。

## 给新项目的启动指令

> 读取本目录 README 和 01–06。以 07 的引擎契约与 08 的工作台设计作为迁移和验收依据。字段 Schema 抽屉与共享表达式编辑器按 09、10 的完整交互和验收场景实现。按 06 的第 0 批验证 Electron、Pi、Langfuse 和现有引擎制品的兼容性，提交实际运行证据与依赖锁定结果。通过后按纵向切片实现。缺少引擎制品时继续独立的桌面与 Pi 验证，单列受阻范围。任何新公共语义先回到相应章节确认。首轮使用合成旅险表单与可控模型验收。

原稿基于 Assemble Studio 提交 `243f9a3d`。接手者可将本目录复制到新项目，按第 07 章列出的路径在引擎仓库查阅协议、设计和测试，并记录实际采用的制品版本。引擎代码与构建制品需另行提供，模型凭证由使用者在本机配置。
