- ADR-03-00 / EXT-1 / EXT-2：外部 I/O、缓存、重试、异步校验执行、上传、提交与工作流归 Host / View Adapter，替代旧架构中的 Resource Manager、Runtime 发起 Capability 请求、Universal Capability Registry 和外部 Action Pipeline。

- B5 / B8：Command 与实际变化不要求 1:1，数组联动复用稳定身份与词法 Scope。
- B6：稳定发布、执行失败不部分成功；业务 invalid / Parse Failure 不自动拒绝正常编辑。
