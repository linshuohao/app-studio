## 实施边界
共用组件位于 apps/studio/src/components/json，按原词法 token 位置编辑节点，避免 JS 对象 / 数值反序列化导致重复键或大整数丢失。只有明确修改的值或键重新编码，未修改词法保留；树 128 层 / 4000 节点上限，超过时仍可切换原文。Studio 当前缓冲保存 / 复制语法校验、压缩后 16 KiB；历史按版本复制和 API 原始保存保持既有行为。
发布确认单独加载所选版本的 views，目标与版本绑定，多视图需显式选择；未知结果沿用冻结回执。URL 保留页面与确定资源身份；路由加载与变更忙碌独立，过期请求取消应用。历史加载由同一 effect 管理，离开保护涵盖复制和发布回执。未知资源不回退其他对象。
目录以实际 manifest、资产 README、工程示例和包内 core 函数说明生成；不虚构制品。成员冲突与最后管理员保护分开；解绑后重新读取绑定或回到登录。Host 实例有编号，默认复用，同发布新增实例显式触发。
## 审查与证据
独立源码 reviewer 提出导航加载锁死、历史响应覆盖、发布 URL 与身份错配、待确认回执保护、未修改转义和 Host 输入不同步，逐项修复；实际测试与最终审查见 tasks.md。手工验收仅使用隔离预览数据库，不触碰原 manual-mvp 数据。

## 本轮追加授权
用户追加对象 JSON 整块编辑、四空格展示、全部页面宽高与换行边界、自定义发布名称。对象编辑先校验类型再保留原 token 压缩；新发布 name 为可选 80 字符单行名称，不代替身份。数据库追加可空列；无名称保留旧幂等指纹，命名受理快照冻结并随回执返回。页面四档宽度检查覆盖列表、工作台、历史、发布、目录、成员、账号与 Host，局部长内容滚动不挤出整页。
