## 范围

用户确认表单管理列与操作密度、配置工作台分区，并授权接入真实接口和浏览器验证。视觉采用黑白灰。依照 [Platform / Studio 最小 MVP](../../../docs/design/platform-studio.md#platform-authoring-mvp) 与 [RBAC](../../../docs/design/platform-studio.md#rbac-form-actions)。

- 表单列表展示最近保存与最近发布。列表进入配置、历史和发布详情。
- 配置编辑、检查、预览、发布与 Host 沿用真实 API，增加可选 JSON 格式化。
- 保留现有数据库及不可变历史。不变更 GitHub 身份机制或成员管理范围。
