## 内部方案与影响

JSON 编辑器持有草稿撤销历史。面板使用原文 token 的位置写入局部变更，一次用户应用产生一条记录；字段删除和所属对象必填同步作为一次操作。选择用 JSON Pointer 关联节点。重复键、复杂引用和无效 JSON 在原文处理。
