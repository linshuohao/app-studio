## 实施设计

继续使用已安装的物料契约、共享字段选择器与 Compiler。简单属性在节点设置中直接编辑，选项列表采用原位展开，将显示名称与写入值并排呈现。固定选项可在列表内调序，现有字面量包装及其他已编写的配置保留。

右栏临时值只进入本布局的预览请求。实时预览采用既有 Web Renderer，校验失败时保留上次可用实例。应用前核对完整属性和 Compiler 检查结果，经共享草稿写入一次。未应用输入沿用工作台离开保护。确认放弃使未返回的检查结果失效。

## 验证边界

使用 Studio 家庭出行模板引用的实际 desktop 定义，验证右栏原位编辑、预览保留试填、应用、撤销、重做及版本重开。独立源码审查覆盖迟到响应、预览 Runtime 生命周期、同节点映射与属性互锁，以及不完整数字恢复。

同工作区的校验模块切换到独立编辑器后，既有跨模块切换用例仍寻找旧的 constraints 占位和根级 JSON 入口。首次完整执行中该用例失败，其他 18 项通过。归档检查保留布局、物料及其余导航用例，排除此并行模块用例。
