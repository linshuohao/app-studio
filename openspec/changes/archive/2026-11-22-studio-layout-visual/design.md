## 实施取舍

每个布局保留一个 ViewNode。新建以 section 空插槽为起点，显示名写入非执行 metadata.studioLayoutNames。复制直接复制节点原文，模板和数据模型继续共享。画布、侧栏和大纲在一次编辑中只针对当前 key。

插入和移动使用原始 JSON token 位置，先验证已安装物料的插槽，再检查子树相对引用实际指向的声明；同名但不同声明的作用域不可交换。配置编辑器通过共享 commit 提交单次原文更新。物料与检查使用 Studio 的真实 Web Catalog。若旧草稿的错误妨碍整表检查，在 Compiler 中独立核验目标节点及其原词法环境、数据模型和共享声明。检查期间切换位置或关闭编辑器会使旧结果失效。

## 验证依据

模型用例核对真实旅险定义、词法引用和移动反例。浏览器覆盖配置、检查、撤销、保存重开与受控 Host。实施证据只适用于本次核验范围。

本地浏览器复现并修复了旧结构错误遮住新表达式类型错误的情况。检查发送紧凑 JSON，草稿保留原文；取消插入和改变目标后过期结果不会写回。窄屏大纲保持独立滚动位置。遇到含歧义、递归或大规模重复引用的字段树，保留根字段和 JSON 入口，并隐藏无法完整证明的覆盖统计。

## 验收范围

运行命令收录于 workflow.json。浏览器使用本机 Chrome、独立 Studio/API 端口和临时 PostgreSQL 数据库。受控 Runtime 使用实际物料；Host 请求与事件使用 Studio 提供的模拟处理器。完整旅险定义超过现有版本接口 16 KiB 限制，双布局使用真实 Compiler 验证；保存重开使用限额内的多布局配置。
