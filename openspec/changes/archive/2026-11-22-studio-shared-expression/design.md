## 预检和方案

- 原型使用字段、函数和作用域的固定旅险样例。Studio 从当前定义取得 Schema 和具名表达式，从真实 Catalog 取得纯函数签名，从布局祖先或规则声明取得词法绑定。有序绑定链保留声明顺序。
- 共享组件输出原文表达式。外层分别负责 `$expr` 包装、属性暂存、规则局部检查和共享草稿应用。邻接节点按 token 编辑保留。复杂递归或暂缺表单控件的节点使用表达式 JSON。
- 条件树展示 AND/OR 及其求值结果。验证复用 Studio 的 Compiler 预览接口和 Web 函数注册。用只含声明、词法绑定和单个求值位置的定义启动临时 Runtime，不触发原表单的 Host 行为。支持样例字段、JSON、只读上下文和重复区成员。校验投影与事件载荷由相应的表单预览提供。
- 校验布尔条件使用目标物料布尔契约。一般属性额外按其 Schema 标明样例返回值是否相容；外层应用仍检查原定义。撤销保留当前编辑入口的事务粒度。
