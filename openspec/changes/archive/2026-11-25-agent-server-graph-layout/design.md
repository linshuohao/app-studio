## 实施边界

统一 Graph 的定义、路由、状态、节点、工具、提示及中间件归入 `agent/`。会话轮次协调与创作事实分属会话和表单创作业务模块。HTTP 响应和公开进度投影归 Agent Server 自己的 `api/`。保留原 Graph 节点 ID、次序、状态键、工具名和结构化模型名。使用已知类型与原日志标识的显式映射保持读写兼容，步骤匹配及失败恢复策略沿用已有实现。

## 对照证据

改造前在主分支 `19f7c4b2` 的实际工作区执行同一套测试，76 项通过，3 项因未提供 PostgreSQL 测试库跳过。对照样本从该工作区生成，包含四个节点中断点、历史 SQLite 轮次、统一 Graph 拓扑和 Agent Server 的 OpenAPI 与代表性 HTTP/流帧输出。独立复核对照 HTTP 帧时排除了时间戳。
