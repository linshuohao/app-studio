# 本次验收增量


## ADDED Requirements

### Requirement: 目录重整的行为等价验收

重整后的 Agent Server SHALL 维持现行轮次 Graph 和既有接口、工具、事件及执行日志兼容性。

#### Scenario: 同一组请求在新旧目录执行

- **WHEN** 对照问答、创建澄清、候选编译、失败修复和同轮重试
- **THEN** Graph 节点、路由、业务结果、模型与工具调用及公开事件符合原契约

#### Scenario: 重构前的轮次在新服务恢复

- **WHEN** 使用重构前写入且未完成的执行日志继续原轮次
- **THEN** 服务按原步骤和类型标识恢复，复用已完成调用，继续剩余执行
