# Studio 查询目录和任务参考

## Why

单有领域 Contract 时，预检仍容易遗漏已有组件、真实 Token 或语言框架做法。用源码派生目录和已审阅的上游参考提供可查询的事实。

## What Changes

按用户确认，从实际公开组件入口、Handbook 和 CSS 构建 Studio 目录，在集中 AI 上下文中按任务提供 TypeScript、Python 和框架参考。选用原文摘录并保留版本和许可，以新会话验证。

## Impact

影响 Studio AI 查询、Skill 加载和文档维护入口。门禁仍沿用上一批已接入范围。来源见[工作流](../../../docs/design/workflows.md#workflow-ai-context)与[维护手册](../../../docs/README.md#maintain-ai-context)。
