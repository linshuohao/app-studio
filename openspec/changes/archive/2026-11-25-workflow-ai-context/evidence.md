# 试点验收证据

基线为本地 `main` 的 `790cb40b` 加当前工作区。验证保留其他活动 Change、本地业务源码和已有生成物的归属。试点没有改变远端必需检查。

| 路径        | 实际结果                                                                                                                                                                                           |
| ----------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| AI Contract | `build_contracts.py --check` 校验 6 条生效条款。4 项回归覆盖候选隔离、生成视图过期、索引与来源解耦、扩读和活动 Change 消费者交集。                                                                 |
| 按需加载    | TreeView 路径命中两条 Studio 条款、10 个消费者与两个检查。加入 `studio-agent-submission` 才加载 API 条款。Array Editor Manifest 路径只匹配资产打包条款，列出 5 个消费者。                          |
| Studio      | `STUDIO_TEST_BROWSER_CHANNEL=chrome pnpm handbook:check:tree` 重建两套 Handbook 例子并通过 7 项 Chrome 用例。覆盖目录打开三个实际组件、键盘、焦点恢复、单多选、回显、取消、绑定、禁用与收窄布局。  |
| 资产        | `pnpm exec turbo run build --filter='./packages/*'` 新鲜构建 7 个包。 `pnpm packages:check` 通过，独立安装真实 tarball，静态入口与 15 个物料、8 个纯函数登记一致，既有包外运行及 Schema 检查通过。 |
| 资产反例    | 单元反例覆盖遗漏出口与错误 ID。另解包实际物料 tarball 到临时目录，先验证 15 个出口，再将 `arrayEditorManifest` 暂时改名，检查准确报告缺少 `array-editor` 的出口。                                  |
| 文档        | 阅读生成与 `--check`、35 项文档工具用例及搜索回归通过。                                                                                                                                            |

本地打包测试使用按现有版本填充的临时 pnpm 缓存。Studio 试点使用独立 Handbook 运行器和 Chrome，覆盖范围为公共树和选择器，完整生产 Studio 路径、其他组件、三浏览器矩阵、远端门禁和宿主自动加载仍待验证。API 条款只做路由试验，Service、其他工程层和所有消费者的自动发现仍待覆盖。并行变更交集是复验提示，以现有指纹验证决定收据有效性。
