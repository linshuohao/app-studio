## 受控复现证据

- PostgreSQL 与 Runtime 样本：50 条原始错误逐条调用执行器，15 条联动条件错误得到相同异常，35 条返回阶段暂不支持。另覆盖越权、发布不匹配、错误签名不同、现场与发布不一致、函数制品不可用、展开预算及过期。
- Agent API 与 Graph：验证受信用户和空间传递、同轮重试复用结果、无模型调用，以及含原始字段的异常回执不会进入对话或执行日志。
- Chrome：`STUDIO_TEST_DIAGNOSTIC_REPLAY=1` 通过 Studio 错误详情引用同一次发生并发送调查请求，经实际 Platform、PostgreSQL 与 Agent Graph 返回复现结论；会话不显示原始填写值。

## 配置修复证据

- Chrome：在真实 Host 触发联动除零，通过错误引用在 Agent 会话展示候选补丁，并验证原填写值未进入回复。
