## ADDED Requirements

### Requirement: 受控访问与当前授权

依据 [平台 RBAC](../../../../../docs/design/platform-studio.md#rbac-enforcement)，首轮 MUST 通过本地初始化命令原子建立唯一默认空间及首位管理员。内置登录建立可撤销会话。受保护请求按当前账号、成员、权限及资源归属裁决。

#### Scenario: 首用与退出

- **WHEN** 空库由操作者初始化，管理员通过内置凭据登录并读取访问上下文，随后退出
- **THEN** 登录期间可获取当前空间和权限，退出后原令牌无法读取或写入
- **AND** 重复或并发初始化至多建立一个管理员，未授权请求无法创建管理员

#### Scenario: 查看者或资格变更

- **WHEN** 查看者读取表单，或成员在登录后被停用、撤回编辑权
- **THEN** 仅有当前查看权的成员可读取所属空间的表单，缺少编辑权的请求无法创建或保存
- **AND** 越权请求无法通过已成功的幂等键取得写入回执

### Requirement: 表单与不可变配置版本

依据 [创建和保存](../../../../../docs/design/platform-studio.md#authoring-save)，创建 MUST 只建立表单。每次独立成功保存 MUST 追加完整原文版本，同一请求重试复用原结果。

#### Scenario: 首次保存、独立追加及重开

- **WHEN** 管理员创建并打开表单，保存无效 JSON，再从同一来源发出两个独立保存
- **THEN** 创建后无配置版本，首次保存和两次独立保存各返回不同版本
- **AND** 重开取追加顺序靠后的版本，旧版本与精确原文保留

#### Scenario: 幂等与提交失败

- **WHEN** 并发重放同一请求，成功后重试，或者同键改变输入
- **THEN** 同键同参返回一个持久结果，同键异参拒绝
- **AND** 中途失败不会遗留表单、版本或回执，归档表单无法追加

#### Scenario: 真实重启

- **WHEN** 使用同一 SQLite 文件停止并启动 API 进程
- **THEN** 业务数据及未过期的有效会话恢复，原回执可重放，已撤销会话依然无效

#### Scenario: 保存等待与失败

- **WHEN** 浏览器在保存期间继续编辑，或服务器拒绝保存
- **THEN** 成功回执只确认发送时的文本，后续及失败的输入保留在编辑器
