# date-picker · 日期选择

选择单个公历日期。用 `field` 为控件提供字段标签和校验提示。

- Binding `value` 接受严格的 `YYYY-MM-DD` 公历日期字符串或 `null`；清空写 `null`。
- 手输按 Enter 或失焦提交。无效格式、无效闰日和超界输入保留在本地并显示提示。日历选中即提交，关闭日历不产生额外写入。
- `min` / `max` 是包含边界的可选日期，约束可选日期和手输提交。`disabled`、`readOnly` 阻止编辑，`placeholder` 默认为 `YYYY-MM-DD`。
- 显示和提交公历日，不经过浏览器所在时区；Host 改值覆盖尚未提交的草稿。字段业务校验继续由表单配置负责。
