# date.ageInYears

`date.ageInYears(birthDate, asOfDate)` 返回截至指定日期已经满的周岁数。两个参数按顺序传入，均为严格的公历日期字符串 `YYYY-MM-DD`，年份范围为 0001–9999。调用方显式选择业务基准日，例如用起保日判断起保时年龄。函数不读取当前时间或时区。

到达当年生日当天即增加一岁。2 月 29 日出生者在非闰年按 2 月 28 日为当年生日，在闰年按 2 月 29 日。出生当天返回 `0`。缺参、空值、格式或日期无效、计算日期早于出生日期时返回 `null`。比较年龄阈值前先处理 `null`。

| 出生日期 | 截至日期 | 返回值 |
| --- | --- | --- |
| 2008-02-29 | 2026-02-27 | 17 |
| 2008-02-29 | 2026-02-28 | 18 |
| 2008-02-29 | 2028-02-28 | 19 |
| 2008-02-29 | 2028-02-29 | 20 |
| 2009-02-29 | 2026-02-28 | `null` |

函数只计算年龄。年龄区间、监护人要求、计划资格和错误字段由调用方的业务规则决定。如果业务采用不同的闰日生日规则，应选择符合该规则的能力。
