业务组件 / 联动

ActionEditor · 动作配置

配置规则中的一条动作。选择类型后，在同一列填写对应字段，应用后写入当前工作稿。

交互预览

试着将设置字段切换为更新对象，添加属性并配置表达式。批量命令可展开子项，整批一起应用或取消。

从动作顶部的「JSON 编辑」查看完整结构。使用值编辑区下方的「验证表达式」打开样例试算弹窗，关闭后继续编辑动作。

有目标字段或目标数组的动作在空间充足时把动作类型和目标放在同一行，窄面板中自动换行。

属性与行为

initial? · string
已有动作的 JSON 原文；新增可省略。更换编辑对象时使用新的 React key 隔离工作稿。
kind? · ActionKind
新增时的初始类型，默认 set。支持 set、patch、remove、array.insert、array.remove、array.move、host.emit、batch。
fields · ReactionField[]
当前可见字段，包含 ref、schema、label、depth 和可选 title、description。scope 提供当前规则的词法绑定。
manifests · PureFunctionManifest[]
当前函数目录。named、functionDocs 和 verification 可按场景提供具名表达式、函数说明与验证上下文。
onApply(raw, isCurrent) · Promise<void>
提交结构有效的动作原文；异步检查结束后核对 isCurrent() 再写入。失败抛出错误，编辑器显示原因并保留输入。
onPending(pending: boolean)、discard()
报告草稿或检查中状态；取消由调用方恢复已应用的动作或移除未应用的新建项。组件没有自定义 slot。

新增和编辑动作

从有序动作列表打开标准宽弹窗。顶部使用 EditorViewSwitch 切换表单和 JSON，底部应用动作时执行规则校验。取消会丢弃弹窗中的动作草稿。
