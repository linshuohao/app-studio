AttemptHistory · 轮次进度

查看 AttemptHistory 代码入口

接收一个轮次的公开记录 attempt、禁用状态 disabled 和可选的继续处理回调 resume。继续处理时可传入 liveEvents，将新收到的公开事件接到已保存的过程之后。会话页和表单侧栏共用。

已完成的阶段保留一行结果，可以逐条展开过程。当前步骤的动画位于最下方，点击可查看仍在处理的阶段。 系统启用减少动态效果时，运行指示保持静止。回合结束后，回复顶部显示折叠的用时和阶段摘要，正文下方可附上生成的配置。 中断后展示已保存的中断位置和原因，有追踪 ID 时可以复制。服务允许恢复时提供继续处理按钮。用 Tab 移动焦点，Enter 或空格展开处理过程或激活按钮。
