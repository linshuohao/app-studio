Button 按钮

用 Button 执行操作。保存、提交等主操作使用主按钮样式。

组件使用代码 · JSX

用法

<Button type="submit" className="primary" disabled={saving}>保存</Button>

组件接口

属性 类型 取值、默认与用法
type? "button" | "submit" | "reset" 普通操作、提交或重置。提交按钮显式传 "submit"。
disabled? / focusableWhenDisabled? boolean 默认 false；后者允许禁用按钮仍可被键盘聚焦。
onClick? React.MouseEventHandler<HTMLButtonElement> 可通过 event.currentTarget 访问按钮。
className? string | ((state: Button.State) => string | undefined) state.disabled 是布尔值，可据此选择样式。
Button · 属性签名与默认值
属性 类型 默认值
focusableWhenDisabled boolean false
nativeButton boolean true
className string | ((state: Button.State) => string | undefined) -
style React.CSSProperties | ((state: Button.State) => React.CSSProperties | undefined) -
render ReactElement | ((props: HTMLProps, state: Button.State) => ReactElement) -

Props · 输入
Button.Props原生按钮属性、disabled、focusableWhenDisabled、className 和 render。
Actions · 行为
onClick(event)点击或使用键盘激活时触发；禁用时阻止激活。
Slots · 组合
children按钮文字及图标。

IconButton · 圆形图标按钮

用于展开、收起和说明等紧凑操作。icon 使用项目 IconName，aria-label 描述动作；展开控件通过 aria-expanded 暴露当前状态。
