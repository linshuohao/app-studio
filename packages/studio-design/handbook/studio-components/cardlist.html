用法

何时使用按外观或摘要浏览条目时使用卡片列表。列表按可用宽度排布；样例沿用物料目录 240 px 最小列宽与 12 px 行列间距。

组合方式列表接收当前页条目和卡片内容。卡片可以提供预览、标题、版本、分类和摘要。整个卡片只保留一个详情入口，预览区只读。加载、无结果或读取失败时，在列表位置呈现对应反馈。

物料示例本例向 CardList 传入本地物料条目，通过独立的 Pagination 切换当前页。Studio 的 MaterialCard 在靠近可视区域后加载运行时预览；目录、目录插入和布局物料选择复用同一种卡片，各自处理打开或选择。

MaterialCard物料目录 
<CardList label="可用物料" items={pageItems} itemKey={m => m.id + ":" + m.version} renderItem={m => <MaterialCard asset={m} onOpen={() => open(m)} />} />

组件接口

属性 类型 取值、默认与用法
label string 必填，供辅助技术识别整组卡片。
items readonly T[] 必填。T 由页面定义；例如 { id: string; version: string; title: string }。传当前页，空列表传 []。
itemKey (item: T) => React.Key 必填。返回稳定键，例如物料采用 id + ":" + version。
renderItem (item: T) => React.ReactNode 必填。接收一条完整记录，返回卡片 JSX。
empty? React.ReactNode 可选。items 为空时的提示或操作。
Props · 输入
label: string · items: readonly T[] · itemKey: (item: T) => React.Key必填。列表接收当前页；物料可用 id 和 version 组成键。
网格尺寸卡片最小宽度和间距使用 Studio 布局默认值。
Actions · 行为
卡片激活由 renderItem 提供调用方给卡片传 onOpen；目录打开详情，插入场景选择物料。列表自身只排列条目。
Slots · 内容
layout="fill" · filters · pagination父容器提供可用高度。筛选区与分页分居上下，只有中间的卡片结果滚动。外围与页面内容边缘对齐。
renderItem: (item: T) => ReactNode必填。可组合预览、标题、版本、标签与摘要。
empty?: ReactNode可选空态。请求中和失败由页面根据数据源状态展示。
