CodeBlock · 代码高亮

统一展示只读的配置原文、接口类型、接入代码与 Markdown 代码围栏。

接口与用途

  • source 接受原文字符串，选中和复制时保留内容与缩进。
  • language 支持 JSON、JavaScript、TypeScript、JSX 和 TSX，默认显示纯文本。
  • label 提供可访问名称，同屏有多个片段时可用于区分用途。
