FieldTree · 字段树

接口与用途

字段页、布局字段结构和 FieldPicker 共用 FieldTree。通过 nodes 传入稳定 id、parentId、名称、可选路径和元信息；展开状态由调用方管理。树行使用 树形列表字阶。

配置 展示与行为
showPath 默认显示路径。关闭时省略路径，保留单行横向滚动。
metadata 默认显示类型和静态必填。树宽达到 420 px 时说明靠右，否则另起一行左对齐。fields 控制可见项及顺序，extra(node) 补充短文本。传 false 隐藏全部说明。例如关联信息由布局页计算后传入。
selection 浏览 none、单选 single、多选 multiple。选择以节点 ID 表示，按受控 value 回显。浏览时可通过 onActivate 打开详情。
selectable / disabledReason 不可选分组省略选择控件。禁选节点保留灰显控件和原因，仍可展开其子节点。
disabled / renderActions 整树禁用时暂停选择、拖拽和行操作，保留展开。行操作通过插槽提供，使用组件给出的 tabIndex 与 disabled。

状态与操作

用方向键浏览和展开，Enter 或空格触发选择。选择模式下，禁选原因可通过悬停或聚焦查看。交互样例可切换浏览、单选、多选、路径与说明显隐及禁用。
