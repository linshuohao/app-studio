组件说明

Field 表单字段

将标签、输入控件和提示直接放入 Field.Root。Label、Description 和 Error 与可聚焦控件自动关联。

组件使用代码 · JSX

用法

<Field.Root name="title">
  <Field.Label>名称</Field.Label>
  <Input required />
  <Field.Description>填写表单名称。</Field.Description>
  <Field.Error match="valueMissing">请输入名称</Field.Error>
</Field.Root>

组件接口

属性 类型 取值、默认与用法
name? string 表单字段名。
disabled? / required? boolean 默认 false；分别控制交互和原生必填约束。
validationMode? "onSubmit" | "onBlur" | "onChange" 字段设置优先于 Form 的设置。
validate? (value: unknown, values: Form.Values) => Result | Promise<Result> Result 为 string | string[] | null | void。返回消息表示无效，返回 null 或不返回表示通过；异步校验不会阻止表单提交。
invalid? / touched? / dirty? boolean 可由外部传入无效、已触碰、已修改状态。
actionsRef? React.RefObject<{ validate: () => void } | null> 校验当前字段。
Field.Error.match? boolean | keyof ValidityState 例如 "valueMissing" 对应必填项缺失；true 用于由外部决定展示时机。

完整部件说明与示例

Props · 输入
Field.Root.Props · name · disabled · validate字段名称、校验及禁用状态由 Root 提供。
Actions · 行为
actionsRef.current.validate()触发字段级校验；具体输入事件由子控件提供。
Slots · 组合
Field.Label · Input / Field.Control · Field.Description · Field.Error每个字段放一个主控件，可按需添加帮助和错误说明。
