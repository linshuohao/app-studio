用法

<Dialog.Root open={open} onOpenChange={setOpen}>
  <Dialog.Trigger>打开</Dialog.Trigger>
  <Dialog.Portal><Dialog.Backdrop />
    <Dialog.Popup><Dialog.Title>选择物料</Dialog.Title>{content}<Dialog.Close>关闭</Dialog.Close></Dialog.Popup>
  </Dialog.Portal>

组件接口

属性 类型 取值、默认与用法
open? / defaultOpen? boolean 受控打开状态或非受控初值；初始默认关闭。
modal? boolean | "trap-focus" 默认 true；false 允许与外部交互，"trap-focus" 限制焦点但允许外部指针交互。
disablePointerDismissal? boolean 默认 false；为 true 时点击外部不触发关闭。
onOpenChange? (open: boolean, details: Dialog.Root.ChangeEventDetails) => void details 提供 reason、原生 event 和 cancel()，可区分 Esc、按钮和外部点击。
onOpenChangeComplete? (open: boolean) => void 打开或关闭过渡完成时通知。

完整部件说明与示例

Props · 输入
open / defaultOpen · modal沿用 Root 状态与模态行为。
Actions · 行为
onOpenChange(open, eventDetails) · onOpenChangeComplete(open)打开或关闭时通知页面；过渡完成后触发完成回调。
Slots · 组合
Trigger · Portal · Backdrop · Popup · Title · Close正文和操作区由页面组合并应用 Studio 样式。
