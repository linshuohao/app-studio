PageHeading · 页面标题与操作

统一 Studio 页面标题、返回入口和页面级操作的布局。

接口与用途

title页面标题。传入字符串时可以启用组件内联编辑。
back可选的返回按钮，提供名称、事件和禁用状态。
description标题下方的说明或状态。
children页面右侧的操作。空间不足时可换行。
rename可选的编辑配置，由页面提供字段名称、保存回调和禁用状态。禁用期间无法修改或提交标题，保存失败时保留输入。

点击标题或按 Enter 开始编辑。输入后按 Enter 或移开焦点保存，按 Escape 取消。异步保存完成时，如果焦点已转到其他控件，焦点保留在该控件。
