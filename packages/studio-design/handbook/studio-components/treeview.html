在分层数据中浏览、展开和选择节点。字段大纲用它切换详情，字段选择器用它承载单选或多选。

单独打开预览
组件使用代码 · JSX

选中「姓名」，再展开「联系方式」。选中项仍为「姓名」，可以横向滚动查看长字段名。单独打开预览可切换密度。

接口

从 Studio 基础组件公共入口导入 TreeView 和 TreeViewNode。每个节点提供唯一字符串 id 与可访问名称 label。子节点的 parent 指向父节点 ID；根节点省略 parent。同级节点按输入顺序展示。

属性 用法
label、nodes 树的可访问名称与节点列表。节点的 selected 表示选中状态。
density regular（默认）沿用常规行布局。compact 收紧行高与缩进，节点按单行排布，超宽时在树内横向滚动。
singleLine 单行排布并在树内横向滚动，可与常规密度同时使用。紧凑密度默认开启。
isExpanded、onToggle 按 id 读取和更新展开状态。调用方可在切换分区后恢复原状态。
renderItem 接收节点及 focusProps。每行把 focusProps 传给一个可聚焦的选择控件，并在其激活时更新选择。需要禁选时，可将焦点交给用于解释原因的元素。
multiple 向辅助技术声明支持多选。调用方提供复选控件、维护选中集合，并决定何时提交。
lockExpansion、toggleLabel 搜索期间可锁定展开操作并显示命中项的祖先；toggleLabel 可自定义展开按钮的可访问名称。

键盘与选择

Tab 进入树，上下键在可见节点间移动焦点，Home / End 到首尾。右键展开当前分支，已展开时进入首个子项；左键收起分支或回到父项。Enter 或空格激活当前行的选择控件。点击展开箭头保留原选择。
