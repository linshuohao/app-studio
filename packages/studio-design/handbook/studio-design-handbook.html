Studio 设计手册

基础组件优先复用 Base UI 的属性和交互，通过 Studio Design Token 统一外观。Base UI 缺少完整组件时，再组合已有控件与原生 HTML。每个条目提供外观示例、可操作样例、调用代码，以及属性、事件和内容区域说明。

Design Token

在 Studio 中使用

在组件页编辑完整 JSX 使用示例即可更新预览。代码包含组件导入、示例数据、状态、事件回调与渲染。展开「属性用途与取值」查看参数含义。「重置示例」恢复初始状态。示例直接导入 Studio 组件，组件或示例源码变更后运行 pnpm handbook:build 更新手册。

基础组件优先从 apps/studio/src/components/ui 导入。业务组件使用各自页面标明的代码入口或 JSX 示例中的导入路径。 

import { Button, DataTable, type Column } from '../components/ui';

Design Icon · 图标

Studio 设计稿、手册样例与页面实现只能选用项目图标库已收录的图标，同一操作使用同一图标。缺少合适图标时，先提交使用场景、需要表达的含义及现有图标的差异，评审通过并纳入库后再使用。页面通过基础组件库使用图标，避免临时手绘 SVG、使用字符或 emoji 代替图标、直接引入其他图标库。

Studio 统一图标库 · Lucide

从项目基础组件库导入 Icon，用 name 选取下表中的图标，例如 <Icon name="Columns3" />。下拉框的 Select.Icon 和 Select.ItemIndicator 已内置展开和选中图标。图标继承控件的文字颜色；带文字的按钮由文字提供可访问名称，纯图标按钮由按钮提供动作名称，例如「列设置」。

页面开发时怎么选

正在设计 先看这些组件 页面负责
管理列表 栅格、筛选、表格或卡片列表，按需组合分页器 查询、权限、分页与返回位置
设置和发布 字段与表单、弹窗 提交、保留输入与错误定位
配置工作台 字段、表达式、动作 作用域、预期类型、草稿和应用时机
候选审阅 对话、差异、试填 接收候选、解决冲突与保存确认

新增组件时先记录真实调用方、输入与输出，再按本手册核对变体、状态、键盘操作和较窄桌面面板。新行为在对应条目集中评审。Renderer 内部及 Host 交付表单遵循各自契约。
