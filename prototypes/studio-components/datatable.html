用法

表格用原生 table 表达行列关系。组件设计复用 Base UI Button 触发排序，用 Menu 的 CheckboxItem 切换列显隐。页面传入数据并管理排序与可见列，分页使用独立的 Pagination。

① 定义列 Column<T>

columns 是只读数组，数组中的每一项是一个列对象。T 是调用方定义的行类型，同一个 T 用于 rows、rowKey 和每列的 render。

属性 类型 取值、默认与用法
key string 必填。列的唯一标识，例如 version。排序和显隐都引用这个值。
title React.ReactNode 必填。列头内容，通常传字符串，例如“版本”。
render (row: T) => React.ReactNode 必填。接收完整的当前行对象，返回单元格内容，可返回文本、数字或 JSX。
sortable? boolean 默认 false。true 表示表头允许请求排序，实际比较或服务端查询由页面负责。
hideable? boolean 默认 false。true 表示列设置允许隐藏这一列。 
type FormRow = { id: string; name: string; category: string; published: boolean; version: number };

const rows: FormRow[] = [
  { id: 'travel', name: '旅险投保', category: '保险', published: false, version: 3 },
  { id: 'medical', name: '境外医疗', category: '保险', published: true, version: 8 },
  { id: 'expense', name: '费用报销', category: '财务', published: true, version: 4 },
];

const columns: readonly Column<FormRow>[] = [
  { key: 'name', title: '名称', render: row => row.name },
  { key: 'category', title: '分类', render: row => row.category },
  { key: 'status', title: '状态', render: row => row.published ? '已发布' : '草稿', hideable: true },
  { key: 'version', title: '版本', render: row => 'v' + row.version, sortable: true },
];

第一行显示「旅险投保 · 保险 · 草稿 · v3」。列标识 status 可以和行属性 published 不同，render 决定单元格显示什么。

② 点击表头排序

在操作样例的版本表头连续点击三次。全部条件下，每页 3 条时，首页依次显示 v1、v2、v3（升序），v8、v7、v6（降序），再恢复 v3、v8、v4（原顺序）。表头把下一状态传给 onSortChange，页面按数值比较版本，对全部匹配行排序后再取当前页。 

type Sort = { key: string; direction: 'asc' | 'desc' } | null;
const [sort, setSort] = useState<Sort>(null);
const [page, setPage] = useState(1);
const pageSize = 3;
const ordered = sort?.key === 'version'
  ? [...rows].sort((a, b) => sort.direction === 'asc'
      ? a.version - b.version
      : b.version - a.version)
  : rows;
const pageRows = ordered.slice((page - 1) * pageSize, page * pageSize);

<DataTable label="表单" columns={columns} rows={pageRows} rowKey={row => row.id}
  sort={sort} onSortChange={next => { setSort(next); setPage(1); }} />

③ 在列设置中切换显隐

打开操作样例右上角的「列设置」，取消「显示状态列」。此时回调返回 ['name', 'category', 'version']，状态表头与整列单元格一起隐藏。重新勾选后按 columns 原顺序显示。名称、分类、版本始终可见，当前页和排序保持原值。 

const [visibleKeys, setVisibleKeys] = useState(columns.map(column => column.key));

<DataTable label="表单" columns={columns} rows={pageRows} rowKey={row => row.id}
  sort={sort} onSortChange={next => { setSort(next); setPage(1); }}
  visibleKeys={visibleKeys} onVisibleKeysChange={setVisibleKeys} />

表格结果区

表头与数据行位于同一个可聚焦的横向滚动区，筛选和分页在区外。进入结果区后可以横向滚动，筛选条件和翻页操作保持可见。

用 layout="fill" 填充容器提供的高度，通过 filters 和 pagination 传入筛选栏与分页。容器有可用高度时，分页贴底，表格结果在两者之间滚动。自然高度容器中的分页紧随结果区。筛选栏、表格和分页沿容器内容边缘对齐，外围无边框。

组件接口

排序与显隐

属性 类型 取值、默认与用法
sort? { key: string; direction: "asc" | "desc" } | null 开启排序时传入。key 对应可排序列，direction 为升序或降序；null 恢复默认顺序。
onSortChange? (next: { key: string; direction: "asc" | "desc" } | null) => void 例：点击版本列，从 null 变为 { key: "version", direction: "asc" }。
visibleKeys? readonly string[] 数组元素为列 key。省略时显示全部列；必显列始终保留。
onVisibleKeysChange? (keys: string[]) => void 传回新的可见列 key 集合，例如 ["name", "version"]。
Props · 输入
label: string · rows: readonly T[] · rowKey: (row: T) => React.Key必填，传入当前页和稳定行标识。
columns: readonly Column<T>[]必填。每列包含 key、title、render(row)，可设 sortable 和 hideable（默认 false）。
sort?: { key: string; direction: 'asc' | 'desc' } | null启用排序时由页面传入；null 表示默认顺序。
visibleKeys?: readonly string[]省略时显示全部列；必显列始终保留。
Actions · 行为
onSortChange?(nextSort: { key: string; direction: "asc" | "desc" } | null): void表头依次请求升序、降序、恢复默认。页面对完整结果排序再分页。
onVisibleKeysChange?(keys: string[]): void用户变更列显隐时触发；页面更新显示列，保留查询条件。
Slots · 内容
columns[].title: ReactNode · render: (row: T) => ReactNode标题和单元格插槽，单元格可提供行操作。
empty?: ReactNode当前无结果时显示；省略时使用通用空态。
