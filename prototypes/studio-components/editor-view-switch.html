组件总览

EditorViewSwitch 表单与 JSON 切换

用于同一份配置的表单编辑和 JSON 编辑。两种视图由调用方共享草稿。

用法

import { EditorViewSwitch } from '../components/ui';

<EditorViewSwitch
  value={view}
  onChange={switchView}
  formDisabled={hasInvalidJson}
  jsonDisabled={formBusy}
/>

两个按钮通过 aria-pressed 表达当前视图，支持 Tab 聚焦和 Enter 或空格切换。弹窗中放在标题下方的固定工具栏内。

调用方可在 onChange 中校验格式并决定是否切换。先保留非法 JSON 输入，再提示用户修正。
