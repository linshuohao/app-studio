ExpressionEditor 表达式编辑器

为表单中的一个位置配置计算逻辑，例如判断投保人是否达到最低年龄，或计算某个属性的值。页面指定当前位置允许读取的内容和需要的结果类型，编辑器帮助用户填写并检查表达式。

取值来源

这里打开的是家庭旅行投保表单的「估算总保费」联动。它把被保人列表、出行方案、行程天数和费率规则传给总保费函数。

具名表达式就是给一段计算起名字。 这个表单把「从出发日到返程日的天数（含首尾）」定义为 tripDays。保费函数的「行程天数」参数选择它时，保存的是 {"use":"tripDays"}。试算时，引擎用当前表单的日期计算天数。样例从 2028-02-28 到 2028-02-29，传入保费函数的是数字 2。

业务数据

Studio 通过 useFunctionCatalog 读取 /catalog/functions，再按函数 id 和版本读取详情。编辑器接收 manifests 与文档。选择函数后，按 parameters 创建必填参数，按 optional 和 restParameter 支持追加参数；returns 描述输出类型。每个参数都可以再选函数，子函数的返回值成为父函数的输入，最外层返回类型与使用位置的 expected 对齐。

下面的离线交互稿从项目的核心函数注册表和旅行场景函数生成目录；实际 Studio 使用当前平台目录。

下方的监护人校验取自 guardian-required。表单逐位读取被保人年龄，调用「是否需要监护人」；返回真时，再检查监护人姓名是否已填写。

表达式来源 编辑时看到的内容 协议结果
固定值 数值、文本、布尔值或 JSON 值 原始标量，或使用 { literal } 包装对象与数组
读取引用 用字段选择器显示业务标签与归属 { ref }，保留路径及适用的局部作用域
函数计算 函数名称、参数含义和结果类型，每个参数可继续配置表达式 { op, args }，参数按签名排序
具名表达式 从当前表单可用的具名表达式中选择 { use }，保存引用名称

入参与出参

名称 类型 用途
label string 当前用途，例如“可见条件”或“保费参数”。
raw string 当前表达式的 JSON 原文。编辑器保留无效旧值，可通过 JSON 入口修复。
fields ReactionField[] 可见字段列表。每项包含 ref、schema、depth 和 label，可提供 title 与 description。
manifests PureFunctionManifest[] 目录函数的 id、version、parameters、restParameter 和 returns。
functionDocs? ReadonlyMap<string, FunctionDocumentation> 按函数 ID 获取标题、类别、参数说明和 displayTemplate。
named? Record<string, Expression> 当前表单可引用的具名表达式。
expected? JsonSchema 调用位置要求的结果类型。
showLabel? boolean 是否显示表达式组标题。省略时显示，可在弹窗标题已说明用途时关闭。
advisory? boolean 开启后把类型兼容性作为提示。
allowValidation? boolean 允许选取校验投影；关闭时通过 FieldPicker 选择数据字段。
verification? ExpressionVerificationContext 提供表单与作用域的试算上下文，组件在表达式工具栏中提供验证入口，并在弹窗中运行验证。
onChange (raw: string) => void 将编辑后的表达式原文交回调用方；调用方管理应用、取消和保存。

交互说明

选择「函数结果」后通过分组 Select 选择函数。「逻辑与」和「逻辑或」位于「逻辑组合」分组。根函数和新选的子函数默认展开，圆形箭头用于收起或展开。收起后摘要只占一行；点击右侧「详情」可按参数逐项查看实际取值，并展开子函数和结构化常量。按 Escape 返回「详情」按钮。函数选择框右侧、参数名旁的圆形 i 可悬浮或聚焦查看说明；点击函数 i 可查看完整签名和示例。外层页面负责将当前值写入配置。

弹窗模式

独立编辑表达式使用 ExpressionEditorDialog。传入与内联编辑相同的 raw、onChange、label 和作用域，再提供 title、onClose、onApply。编辑期间由调用方持有草稿，点击右下角主按钮才应用。无效 JSON 禁用应用；busy 期间锁定编辑、应用和关闭。error 显示业务检查反馈，action 可指定提交按钮文案。

宽版弹窗仅显示一次标题，内容区独立滚动。Tab 可到达编辑控件与底部主操作，Escape 关闭当前弹层。
