FieldPicker 字段选择器

页面传入当前表单的字段，用户从中选出绑定目标或监听字段，确认后把字段引用交回页面。

字段模型入参与出参Slots操作样例使用边界

字段层级使用业务组件 FieldTree 字段树。字段选择器负责搜索、候选范围和确认选择。

字段模型

投保表单中，“投保人”和“当前被保人”都包含“年龄”。字段名与路径靠左，类型等说明在宽树中靠右、窄树中另起一行。父子缩进与展开箭头表达归属；多选摘要用“当前被保人 / 年龄”回显，确认后才把引用交给调用方。

从 Data Schema 生成字段树

只有 Data Schema 的页面可以用 fieldsFromSchema(dataSchema) 取得节点树。Schema 提供字段结构与标题；作用域来自当前编辑位置，禁选条件来自本次选择用途。已有字段树的页面可以直接传 fields。FieldPicker 只需要一套树形入参。 

const fields = fieldsFromSchema(dataSchema, {
  scopes: [{ as: 'insured', mode: 'each', from: { source: 'data', path: '/insuredPersons' } }],
  getDisabledReason: node => node.type === 'integer' ? undefined : '需要整数',
});

样例复用旧版的 Schema 引用与作用域解析。数组本身可以作为字段；当前被保人的子字段由明确的逐项作用域提供。标题缺失时，适配层使用业务侧补充的 label，示例回退为“未命名字段”。

节点属性

名称 类型 业务含义与取值
ref DataReference 必填。可交回页面的字段引用，一个列表里每个 (scope, path) 组合唯一。
ref.source 'data' 必填，标记表单数据。选中字段后由页面决定是否进一步组装校验监听或写入动作。
ref.scope string | undefined 可省略。省略表示表单根；提供时是当前可见的局部作用域名称，如 insured。
ref.path string 必填。相对上述作用域的 JSON Pointer；空字符串表示自身，/ 表示空键，键内的 ~ 和 / 分别用 ~0、~1 转义。
label string 必填。面向用户的字段名，可重名，如“年龄”。
type string 必填。本稿用于展示的类型名称，如 string、integer、array 或联合类型说明。供规则及可选插槽使用，字段行默认只显示 label。
disabledReason? string 可选，非空时禁选。原因在鼠标悬停或键盘聚焦该字段时通过浮层显示，不占用行内宽度。禁选父字段仍可展开，子字段分别判断。

children?: readonly FieldOption[] 表示直接子节点。省略或为空表示叶节点；同级顺序取自数组。折叠、禁选和选择各自独立，多选父节点只选中它本身。 

const fields: FieldOption[] = [{
  label: '投保人', type: 'object', ref: { source: 'data', path: '/applicant' },
  disabledReason: '需要整数',
  children: [
    { label: '年龄', type: 'integer', ref: { source: 'data', path: '/applicant/age' } }
  ]
}];

入参与出参

名称 类型 业务含义与取值
fields readonly FieldOption[] 必填。同级字段按传入顺序展示。空数组显示“表单尚无字段”。
label string 必填，说明本次用途，同时用作触发按钮名称和弹窗标题。
multiple? boolean 默认 false。单选用于绑定一个字段；多选用于一次挑选多个字段。
value DataReference | null 或 readonly DataReference[] 必填，页面持有的已确认值。单选初始为空传 null；多选为空传 []。
onChange 见下方按模式区分的签名 必填。仅点击“应用选择”时调用一次。单选须选中一个可用字段；多选可确认空数组。 
type FieldOption = {
  children?: readonly FieldOption[];
  ref: DataReference;
  label: string;
  type: string;
  disabledReason?: string;
  selectable?: boolean;
  required?: boolean;
};

type FieldPickerProps = {
  fields: readonly FieldOption[];
  label: string;
  description?: ReactNode;
  showPath?: boolean;
  metadata?: FieldTreeMetadata<FieldTreeNode & { field: FieldOption }>;
} & (
  | { multiple?: false; value: DataReference | null;
      onChange: (field: DataReference) => void }
  | { multiple: true; value: readonly DataReference[];
      onChange: (fields: DataReference[]) => void }
);

打开时从 value 建立临时选择。搜索、折叠和勾选只更新弹窗；取消或 Escape 丢弃临时选择，焦点回到触发按钮。多选按选择顺序去重，移除后再选排到末尾。已选字段消失或变为禁选时提示失效，单选可改选，多选可移除后再确认。

展示配置

description 提供弹窗内的业务提示。showPath 和 metadata 透传给 FieldTree。可隐藏路径、调整类型与必填的顺序，或通过 metadata.extra 补充短文本。

操作样例

字段行以 32 px 为常规高度，窄树的说明行按内容增高。点箭头展开或收起一支，点标签选择字段。搜索名称或路径时临时展开命中的祖先，清除搜索后恢复原展开状态。长名称和路径在树内横向滚动，搜索与底部操作保持可达。多选的已选区在右侧，窄窗口移至树下。

使用边界

从 Studio 字段选择器 导入 FieldPicker 和 fieldsFromSchema。单选提交一个有效引用，多选可提交空集合。联动的校验投影由调用方配置。
