组件设计稿

Input 输入框

通过 type 选择文本、时间或文件输入。不同类型的取值与事件见对应样例。

文本输入时间选择文件选择组件接口

文本输入

Input 放入 Field 后会自动关联标签和帮助。页面可传原生输入属性。

单独打开预览
组件使用代码 · JSX 
<Input name="title" value={title} onValueChange={setTitle} />

时间选择

本例按分钟输入本地时间，值如 09:30；清空后为空字符串。

单独打开预览
组件使用代码 · JSX 
<Input type="time" min="08:00" max="18:00" step={60} onValueChange={setTime} />

文件选择

原生 change 提供 FileList。文件输入使用非受控方式，由页面决定如何读取或上传。

单独打开预览
组件使用代码 · JSX 
<Input type="file" accept=".json" onChange={e => selectFiles(e.currentTarget.files)} />

组件接口

属性 类型 取值、默认与用法
name? string 表单字段名。
disabled? / required? boolean 默认 false；分别控制交互和原生必填约束。
type? React.HTMLInputTypeAttribute 本手册展示 "text"、"time"、"file"。文本和时间模式使用字符串。
value? / defaultValue? string | number | readonly string[] 受控当前值或非受控初值。时间例："09:30"；文件模式由浏览器维护所选文件。
min? / max? / step? number | string 时间模式 min/max 如 "18:00"，step 按秒，例如 60。
accept? / multiple? string / boolean 文件示例 accept=".json"；multiple 允许选多个文件。
onChange? React.ChangeEventHandler<HTMLInputElement> 文件模式读取 currentTarget.files: FileList | null，每项 File 提供 name、size、type 等。
onValueChange? (value: string, details: Input.ChangeEventDetails) => void 返回输入字符串；details.event 为关联的原生事件。
Input · 属性签名与默认值
属性 类型 默认值
defaultValue string | number | string[] -
value string | string[] | number -
onValueChange ((value: string, eventDetails: Input.ChangeEventDetails) => void) -
className string | ((state: Input.State) => string | undefined) -
style React.CSSProperties | ((state: Input.State) => React.CSSProperties | undefined) -
render ReactElement | ((props: HTMLProps, state: Input.State) => ReactElement) -

完整部件说明与示例

Props · 输入
Input.Props · value / defaultValue支持受控与非受控输入、原生 name、required 等属性。
Actions · 行为
onValueChange(value, details) · onChange(event)文本、时间模式使用 onValueChange 接收字符串。文件模式通过 onChange 读取 event.currentTarget.files，交由页面处理 FileList。
Slots · 组合
render · className样式来自 Studio Token。标签和说明由 Field 组合。
