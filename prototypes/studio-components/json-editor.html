业务组件 / 配置编辑

JsonEditor · JSON 编辑器

用于查看配置原文、编辑复杂属性和修复场景定义。页面传入 JSON 文本并接收每次修改后的原文，决定何时校验业务规则、应用或保存。

交互预览

展开 travelers → 0 → emergencyContact 查看第一位旅客的紧急联系人，或在 coverage → benefits 比较两项保障的限额和除外责任。试着修改「旅险投保」并撤销；也可以切到文本模式，删掉末尾的右花括号，观察修复提示。可单独打开紧凑示例，与默认高度对比。从上方「操作」选择「导入 JSON」，在下方粘贴内容并确认；选择「编辑文本」即可继续修改原文。将 readOnly 设为 true 可切换到查看文档的场景。

组件接口

属性 类型与默认值 调用约定
text string，必填 当前完整原文，支持任意 JSON 根值、空文本和未完成的输入。
label string，默认「JSON 内容」 文本输入区或树区域的可访问名称。
readOnly boolean，默认 true 只读时保留浏览、折叠、定位与复制。
size 'regular' | 'compact'，默认 regular 小弹窗和局部参数编辑推荐 compact。长内容在编辑区内滚动，切换尺寸保留草稿与撤销记录。
initialMode 'tree' | 'text'，默认 tree 首次展示方式。后续切换保留当前草稿。
onChange (text: string) => void，编辑时必填 文本输入即时回传；节点弹窗和导入弹窗在确认后回传一次。
focusPath { path: string; revision: number }，可选 path 为 JSON Pointer，如 /views/main，根为 ""。更新 revision 可再次定位同一路径。
onValidationChange (result: JsonValidation) => void，可选 分别报告语法有效、语法错误、超出检查上限。业务 Schema 和编译诊断由调用方处理。

  | { status: 'valid' }
  | { status: 'invalid'; message: string }
  | { status: 'unchecked'; reason: 'size-limit' };

操作与插槽

层级编辑
对象可添加、重命名和删除属性；数组可追加或删除项。六种值类型均可编辑。修改容器类型会替换其子树，应用前提示影响。
文本与导入
允许逐字修复无效文本。显式格式化只调整字符串外的空白，保留大整数与重复键。粘贴导入先检查，再整份替换。
撤销与重做
节点修改、文本修改与导入使用当前文档的历史。切换查看方式保留历史，切换到另一文档时，调用方用稳定的文档标识作为 React key，隔离历史。
定位与焦点
外部诊断可请求展开并聚焦对应路径。路径失效时显示提示；关闭节点弹窗回到触发操作，删除后回到相邻节点或父节点。
工具栏插槽
toolbarExtra?: ReactNode。可视化分区已接管撤销和重做且没有附加操作时，工具栏不占用高度。放置“检查配置”等当前文档操作，页面使用自己持有的草稿执行。保存、发布或取消整次编辑放在页面操作区。

页面接入

无效原文能否保存？ 编辑器报告检查结果。场景表单可以阻止保存，允许保留无效草稿的工作台可以继续保存。超出树展示上限时，用户仍可查看原文。

跨视图撤销由谁管理？ 单独使用时由编辑器维护历史。工作台同时提供画布和源码时，由工作台持有同一份历史，让用户在画布改动后也能从源码视图撤销。
