LiteralValueEditor 固定值编辑

用于字段默认值、允许值、示例值、表达式固定值、规则匹配值和物料常量。

用法

import { LiteralValueEditor, readLiteral, literalSource } from './literal-value-editor';

<LiteralValueEditor
  label="允许值"
  value={readLiteral('true')}
  allowTypeChange
  onChange={(value) => update(literalSource(value))}
/>

允许切换类型时，左侧选择类型，右侧编辑值。类型由字段或物料契约决定时，只显示值控件。文本和数值用输入框，布尔值用「真 / 假」下拉，对象和数组用「查看 / 编辑」打开 JSON 弹窗。

调用方持有草稿并负责校验及应用时机。数值输入可以暂时为空，应用前使用 literalSource 校验。
