Menu · 下拉菜单

在一个入口中列出针对当前对象的动作。

交互样例

展开「管理」并选择操作。示例禁用复制，模拟表单尚无已保存版本。

使用约定

  • 触发器默认使用带边框的次要按钮，菜单面板沿用同一边框颜色。可显式传入图标触发器，并提供可访问名称。
  • 下拉菜单用于执行动作。保存表单字段值时使用 Select。
  • 页内菜单使用 Portal 和 Positioner。原生对话框里的菜单将 Portal 容器设为对应的 dialog。
  • 使用方向键切换选项，Enter 或 Space 执行，Escape 关闭并返回触发按钮。
  • 动作的权限、确认与结果由调用页面处理。表单归档从菜单进入确认弹窗。

组件 API

import { Menu } from '../components/ui'

<Menu.Root>
  <Menu.Trigger>管理</Menu.Trigger>
  <Menu.Portal>
    <Menu.Positioner align="end">
      <Menu.Popup>
        <Menu.Item onClick={edit}>编辑名称与说明</Menu.Item>
        <Menu.Item disabled={!canCopy} onClick={copy}>复制为新表单</Menu.Item>
      </Menu.Popup>
    </Menu.Positioner>
  </Menu.Portal>
</Menu.Root>
