组件使用代码 · JSX

用法

使用方式放在结果区下方，与结果区左右边界对齐。左侧选择每页条数，右侧显示当前页、总页数、总条数和翻页操作。

输入与行为分页器接收结果总数、当前页和页容量。翻页通知列表重新取数或切片。修改容量或应用新筛选回到首页；总数缩小时修正超范围页码。首页禁用上一页，末页禁用下一页，零条时两者都禁用。

表格与卡片列表示例各自持有分页状态，可独立操作。

<Pagination total={total} page={page} pageSize={size} pageSizeOptions={[10, 20, 50]} onChange={changePage} />

组件接口

属性 类型 取值、默认与用法
total number 必填，筛选后的总条数，非负整数。
page number 必填，从 1 开始。零条时传 1。
pageSize number 必填，当前每页条数，正整数。
pageSizeOptions readonly number[] 必填，例如 [10, 20, 50]；各值为互不重复的正整数，包含 pageSize。
onChange (page: number, pageSize: number) => void 必填。第 2 页切到每页 20 条，一次回调 (1, 20)。
Props · 输入
total: number · page: number · pageSize: number必填。total 为筛选后的非负整数，页码从 1 开始，容量为正整数。
pageSizeOptions: readonly number[]必填。传入去重的正整数并包含当前容量；手册用 3、5、10 示范。
Actions · 行为
onChange(page: number, pageSize: number): void必填。翻页报告新页码和现有容量；换容量只报告一次 (1, 新容量)。总数变化由页面校正页码；空集约定 page=1，显示 0 条。首末页禁用对应操作。
Slots · 内容
固定布局首版内置条数选择、页码摘要、上一页和下一页。分页器作为表格或卡片列表的同级组件。
