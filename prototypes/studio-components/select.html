组件设计稿

Select 下拉选择

单选使用默认模式；需要选择多项时开启 multiple，值为数组。

单选多选选项分组组件接口

单选

单选和多选共用 Select，单选使用默认模式。

单独打开预览
组件使用代码 · JSX 
<Select.Root value={value} onValueChange={setValue}>
  <Select.Trigger aria-label="状态"><Select.Value /><Select.Icon /></Select.Trigger>
  <Select.Portal><Select.Positioner><Select.Popup><Select.List>
    {options.map(item => <Select.Item key={item} value={item}><Select.ItemText>{item}</Select.ItemText><Select.ItemIndicator /></Select.Item>)}
  </Select.List></Select.Popup></Select.Positioner></Select.Portal>
</Select.Root>

多选

启用 multiple 后每次选择会更新值数组。

单独打开预览
组件使用代码 · JSX 
<Select.Root multiple value={value} onValueChange={setValue}>
  <Select.Trigger aria-label="状态"><Select.Value /><Select.Icon /></Select.Trigger>
  <Select.Portal><Select.Positioner><Select.Popup><Select.List>
    {options.map(item => <Select.Item key={item} value={item}><Select.ItemText>{item}</Select.ItemText><Select.ItemIndicator /></Select.Item>)}
  </Select.List></Select.Popup></Select.Positioner></Select.Portal>
</Select.Root>

选项分组

在 Select.List 内使用 Select.Group 包住同一类选项，用 Select.GroupLabel 提供可访问的组名。方向键可跨组移动。单选返回选项值，多选返回跨组选中的值数组。

单独打开预览
组件使用代码 · JSX

示例面板中的 grouped 切换分组结构，multiple 切换多选。

<Select.List>
  {groups.map(({ label, items }) => (
    <Select.Group key={label}>
      <Select.GroupLabel>{label}</Select.GroupLabel>
      {items.map(value => (
        <Select.Item key={value} value={value}>
          <Select.ItemText>{value}</Select.ItemText>
          <Select.ItemIndicator />
        </Select.Item>
      ))}
    </Select.Group>
  ))}
</Select.List>

组件接口

属性 类型 取值、默认与用法
multiple? boolean 默认 false。以下 T 表示一项的值类型。
value? / defaultValue? 单选 T | null；多选 readonly T[] | null 传当前值或初值；单选常用 null，多选常用 [] 表示清空。
items? Record<string, ReactNode> | readonly { value: T; label: ReactNode }[] | readonly Group[] 对象键或 value 是选项值，label 是显示内容。分组对象必须有 items 数组，可携带额外元数据。
isItemEqualToValue? (itemValue: T, value: T) => boolean 默认 Object.is。对象值可按稳定 id 比较。
itemToStringValue? / itemToStringLabel? (itemValue: T) => string 分别用于表单序列化和显示文本。
onValueChange? 单选 (value: T | null, details) => void；多选 (value: T[], details) => void details 为 Select.Root.ChangeEventDetails，含 reason、event 和 cancel()。
onOpenChange? (open: boolean, details: Select.Root.OpenChangeEventDetails) => void 打开或关闭请求。

完整部件说明与示例

Props · 输入
Select.Root.Props · value / defaultValue · multiple默认单选，空选为 null；multiple 模式传入值数组，空选为 []。
Actions · 行为
onValueChange(value, eventDetails) · onOpenChange(open, eventDetails)选择改变时收到新值，面板打开或关闭时收到新的展开状态。
Slots · 组合
Trigger · Value · Icon · Portal · Positioner · Popup · List · Item决定显示文本、箭头、选项与勾选标记。
