Tabs 标签页

在同一页面切换相关内容。跨页面跳转使用页面导航。

单独打开预览
组件使用代码 · JSX

选中状态以横向底线或纵向侧线标识。进入标签栏后用方向键移动焦点，按 Enter 或 Space 激活。也可以开启「activateOnFocus」体验随焦点切换。

用法

import { Tabs } from '../components/ui';

<Tabs.Root defaultValue="overview" size="md">
  <Tabs.List aria-label="表单配置区">
    <Tabs.Tab value="overview">基本信息</Tabs.Tab>
    <Tabs.Tab value="fields">字段配置</Tabs.Tab>
  </Tabs.List>
  <Tabs.Panel value="overview">境外旅行保障</Tabs.Panel>
  <Tabs.Panel value="fields">投保人姓名、证件号码、出行日期</Tabs.Panel>
</Tabs.Root>

组件接口

组件 属性 类型 默认值与用法
Root bordered? boolean 默认 false。开启后在整组页签和内容外显示边框。
Root size? 'sm' | 'md' 默认无外框。横向 md 标签间距 32px，上下留白各 12px；sm 分别为 24px 和 8px。
Root orientation? 'horizontal' | 'vertical' horizontal，同时决定排列和方向键行为。
Root value? / defaultValue? Tabs.Tab.Value 受控值或非受控初值。常用稳定字符串。传 null 表示无选中项。
Root onValueChange? (value: Tabs.Tab.Value, details: Tabs.Root.ChangeEventDetails) => void 接收选中值与 Base UI 事件详情。受控用法在回调中更新 value。
List activateOnFocus? boolean false，方向键移动焦点后需主动确认。
List loopFocus? boolean true，方向键到达末端后可以循环移动。
Tab / Panel value Tabs.Tab.Value 必填，同一组中每个 Tab 唯一，与对应 Panel 使用相同值。
Tab disabled? boolean 默认可用。禁用页签显示灰字，背景透明，悬停显示禁止光标，无法激活。
Panel keepMounted? boolean false。需要保留非当前面板的 DOM 时开启。

Tab 的子元素提供标签文本，Panel 的子元素提供对应内容。为 List 提供可访问名称。其余属性见 Base UI Tabs。
