Textarea 多行文本

复用 Field.Control 的 render 部件呈现原生多行文本框。

交互预览用法接口

交互预览

单独打开预览
组件使用代码 · JSX

用法

<Field.Root name="comment">
  <Field.Label>审核意见</Field.Label>
  <Field.Control render={<textarea rows={3} />} />
</Field.Root>

组件接口

属性 类型 取值、默认与用法
render React.ReactElement 例如 <textarea rows={3} maxLength={500} />；rows 和 maxLength 都是数字。
value? / defaultValue? string（多行文本用法） 传原文，可包含换行。受控模式需在回调中更新 value。
onValueChange? (value: string, details: Field.Control.ChangeEventDetails) => void value 包含完整多行文本，details 提供 reason 与原生 event。
Control · 属性签名与默认值
属性 类型 默认值
defaultValue string | number | string[] -
onValueChange ((value: string, eventDetails: Field.Control.ChangeEventDetails) => void) -
className string | ((state: Field.Control.State) => string | undefined) -
style React.CSSProperties | ((state: Field.Control.State) => React.CSSProperties | undefined) -
render ReactElement | ((props: HTMLProps, state: Field.Control.State) => ReactElement) -

完整部件说明与示例

Props · 输入
Field.Control.Props · renderrows 等 textarea 专有属性放在渲染元素上。
Actions · 行为
onValueChange(value, details)每次编辑回传完整的多行文本。
Slots · 组合
render={<textarea />}沿用 Field 的标签、描述和错误关联。
