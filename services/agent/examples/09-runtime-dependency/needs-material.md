# 旅行险预登记与正式渠道核验

旅客填写联系人姓名和起止日期。姓名必填，最多 40 个字符。起止日期必填，终保日不得早于起保日，且首尾合计最多 30 个自然日。

应用装载时通过只读 Context 提供 `businessDate`，格式 YYYY-MM-DD，含义为北京时间业务日期。起保日必须晚于该日期，最晚能预约到未来第几天以及边界当天是否受理，等渠道确认。

正式应用在本地校验全部通过后，向渠道发送联系人姓名、起保和终保日期。核验返回通过或拒绝，拒绝时含可展示原因。只有本次数据快照通过核验才可正式提交。

请生成可试填本地校验的候选。正式运行时的日期和服务由应用装载时提供。未绑定渠道时，预览可以试填本地部分，并须明确哪些正式流程尚无法验证。
