# 门店旅险咨询回访登记单

## 使用场景

旅行社门店交班时，下一班顾问需要知道哪些旅客要求回电、方便何时联系，以及咨询的大致行程。一张登记单对应一次回访请求。由接待顾问根据旅客口述填写。当前环节只交付登记数据，排班、拨号和保单报价由后续流程负责。

## 录入口径

按下列两个区域和字段顺序展示，初始均留空。除备注外均必填。顾问可以先录入部分信息，交接前一次校验。所有选项均由本需求给定，录入过程中各字段独立。

| 区域     | 字段及交付键           | 录入和交付要求                                                        |
| -------- | ---------------------- | --------------------------------------------------------------------- |
| 回访安排 | 联系人 contactName     | 文本，1 至 40 个字符                                                  |
| 回访安排 | 联系手机 mobile        | 国内手机号，恰好 11 位数字，以 1 开头；按字符串交付                   |
| 回访安排 | 回访时段 callbackSlot  | 上午（09:00–12:00）、下午（14:00–18:00）单选，交付 morning、afternoon |
| 行程意向 | 旅行范围 tripType      | 境内、境外单选，分别交付 domestic、international                      |
| 行程意向 | 预计人数 travelerCount | 1 至 30 人，含边界；按整数交付                                        |
| 行程意向 | 顾问备注 memo          | 选填自由文本，至多 200 个字符                                         |

## 业务验收

顾问登记一名联系人、一个手机号和首选回访时段后，给三名境外游客登记一条回访请求。交班数据须能区分时段、旅行范围和人数；无需填写备注即可完成。手机号少一位或人数为 0 时须阻止交接，并指出对应字段。填写这张表时无需查询客户档案或调用外部服务。
