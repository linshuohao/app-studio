# 物业临时进场审批登记

楼宇管理员接收一个工单的临时进场申请，用于向物业值班台交接。一个工单只有一个区域、一段连续日期，期间每天采用相同的时间窗口。跨午夜或每天时间不同的安排须拆成独立工单。

## 工单和到场信息

| 字段                         | 交付键           | 必填         | 输入与存值                                                                     |
| ---------------------------- | ---------------- | ------------ | ------------------------------------------------------------------------------ |
| 物业工单编号                 | `ticketNo`       | 是           | 6–24 个字符。                                                                  |
| 登记人员                     | `operator`       | 是           | 2–40 个字符。                                                                  |
| 作业区域                     | `area`           | 是           | 办公区（`office`）、仓储区（`storage`）、公共区（`common`）。                  |
| 申请类型                     | `reason`         | 是           | 集中保洁（`cleaning`）、大型物资送达（`delivery`）、例行巡检（`inspection`）。 |
| 开始日                       | `startDate`      | 是           | 真实自然日，格式 YYYY-MM-DD。                                                  |
| 结束日                       | `endDate`        | 是           | 真实自然日，格式 YYYY-MM-DD。                                                  |
| 进场人数                     | `visitors`       | 是           | 1–30 的整数，单位为人。                                                        |
| 每天开始时刻                 | `startHour`      | 是           | 0–23 的整数，单位为整点。                                                      |
| 每天结束时刻                 | `endHour`        | 是           | 1–24 的整数，单位为整点。                                                      |
| 非开放时段说明               | `afterHoursNote` | 按规则或选填 | 12–180 个字符。                                                                |
| 卸货与搬运路线               | `deliveryRoute`  | 按规则或选填 | 8–150 个字符。                                                                 |
| 现场复核人员                 | `reviewer`       | 按规则或选填 | 2–40 个字符。                                                                  |
| 确认已告知现场负责人此次安排 | `confirmed`      | 是           | 布尔值，初始未勾选。提交时必须勾选。                                           |

## 日期和开放时段

日期从开始日至结束日含首尾最多 5 天。开始时刻必须严格小于结束时刻；允许结束为 24:00，含义为当日结束。普通开放时段为 08:00 至 18:00，开始与结束分别允许正好等于这两个边界。任一端越界即显示非开放时段说明且要求填写，改回开放时段后清除说明。日期错误归到结束日，时刻错误归到结束时刻。

## 人数与交付范围

12 人及以上须填写一位现场复核人员，包括刚好 12 人。降到 11 人或更少即隐藏并清除。大型物资送达另要求填写卸货与搬运路线，切换申请类型时清除此字段。人数与路线彼此独立。

工作态可以保存短期输入，值班台交付只接受当前适用字段，省略隐藏说明。物业工单是否已经关闭由 Host 按工单号查验，查不到或已完结时提示原因并保留草稿。

## 时段示例与错误展示

以 8–18 时为例，不显示补充说明；7–18 或 8–19 均显示。7–7 则先提示结束时刻顺序错误。范围边界按整点判断。进场人数、时段、申请类型各自触发对应的显示与清除，任何一次切换不应清除其他分支的内容。

## 验收场景

1. 录入办公区、2 天、08–18 时、11 人、集中保洁，三个补充字段都隐藏。
2. 改为 07–18 时、12 人、大型物资送达，三个补充字段分别出现。填完后只改申请类型，路线清除，另外两项保留。
3. 修正人数为 11、时段恢复 08–18，字段和旧值都消失。再切回 12 人时现场复核人员为空。
4. 已关闭的工单不得交付，日期和人员仍保留。柜台重新输入有效工单号后可以重试。
