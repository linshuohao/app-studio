# 培训设备借用与交还

器材管理员为一个已经立项的课程申请借用设备。一份申请对应同一次交接，单台设备在清单里占一行。申请人可保存尚未填写完的工作值，正式交接前校验全单。此样例止于生成借用记录。

## 申请和交付方式

页面先显示申请人、项目、交付方式和借用期限，配送资料在期限下方出现。签收信息独立于申请人。

| 字段                       | 交付键        | 必填         | 输入与存值                                           |
| -------------------------- | ------------- | ------------ | ---------------------------------------------------- |
| 领用人                     | `requester`   | 是           | 2–40 个字符。                                        |
| 项目编号                   | `projectCode` | 是           | 4–24 个字符。                                        |
| 交付方式                   | `pickupMode`  | 是           | 库房自取（`counter`）、配送到项目现场（`courier`）。 |
| 开始日                     | `loanDate`    | 是           | 真实自然日，格式 YYYY-MM-DD。                        |
| 归还日                     | `dueDate`     | 是           | 真实自然日，格式 YYYY-MM-DD。                        |
| 现场地址                   | `siteAddress` | 按规则或选填 | 8–160 个字符。                                       |
| 签收联系人                 | `siteContact` | 按规则或选填 | 2–40 个字符。                                        |
| 签收手机号                 | `sitePhone`   | 按规则或选填 | 以 1 开头的 11 位数字，按字符串保存。                |
| 我已核对借用期限和归还责任 | `accepted`    | 是           | 布尔值，初始未勾选。提交时必须勾选。                 |

## 期限和切换

首尾均计入借用期，最多 14 个自然日，同日借还视为 1 天。倒序和超期的提示归到归还日。选择配送时，地址、签收联系人和手机号都必填。交付方式改回库房自取之后，签收信息如何处理，需要仓储与配送团队确认。再次选择配送时填写新资料；借用期和设备行保持原值。

## 设备清单

至少 1 台、最多 8 台。系统新增时生成稳定的 itemId，资产编号由库房标签录入。清单可删，不要求填写固定顺序。空行参与提交校验。

| 字段         | 交付键         | 必填         | 输入与存值                                                         |
| ------------ | -------------- | ------------ | ------------------------------------------------------------------ |
| 设备资产编号 | `assetTag`     | 是           | 3–30 个字符。                                                      |
| 用途         | `useType`      | 是           | 室内课程（`indoor`）、户外采集（`outdoor`）、车间测试（`bench`）。 |
| 交接说明     | `handoverNote` | 按规则或选填 | 0–200 个字符。                                                     |
| 防雨保护说明 | `weatherCover` | 按规则或选填 | 8–120 个字符。                                                     |

## 设备规则与交付

切换为户外采集时，当前设备须填写防雨保护说明，并只在该行显示说明项。切回其他用途时删除该行说明，其他行保持原值。资产编号按去首尾空白并转大写后的值比较，同一张单的重复资产在两行都显示冲突。Host 的本地校验器负责这项比较，并在提交时投影清理后的资产编号。

交接提交包含申请人、项目、借还日期、交付方式、按录入顺序排列的设备及确认布尔值。库房自取的交付记录省略签收资料。提交失败保留填好的单据。

## 验收场景

1. 选配送并填写签收资料后切到自取，记录哪些字段需要表单处理，签收资料保留或清除的预期待业务确认。
2. 从 3 月 1 日借到 3 月 14 日通过，改到 15 日触发超期。把结束日调整到 2 月 28 日触发倒序。
3. 两行资产编号分别填 `ab-019` 和 `AB-019`，两行各出一条重复提示，删除其中一行即取消冲突。
4. 两台设备均为户外采集，补齐说明后只改第二行的用途，第二行的保护说明从交付中消失，第一行保留。
