# 食品配送批次收货与隔离

连锁食堂仓储人员按配送单记录普通食品到货。一行是货品编码和批号组合，库存系统随后据此入库或隔离。允许同一批车上同时有常温、冷藏和冷冻货品，按每行独立判断。金额和赔付由另一流程处理。

## 配送信息

| 字段                 | 交付键         | 必填         | 输入与存值                             |
| -------------------- | -------------- | ------------ | -------------------------------------- |
| 配送单编号           | `shipmentNo`   | 是           | 6–28 个字符。                          |
| 收货人               | `receiver`     | 是           | 2–40 个字符。                          |
| 到货日期             | `receivedDate` | 是           | 真实自然日，格式 YYYY-MM-DD。          |
| 收货库               | `site`         | 是           | 北区库（`north`）、南区库（`south`）。 |
| 承运方简称           | `carrier`      | 是           | 2–60 个字符。                          |
| 班次备注             | `shiftNote`    | 按规则或选填 | 0–200 个字符。                         |
| 已逐批核对标签与实物 | `confirmed`    | 是           | 布尔值，初始未勾选。提交时必须勾选。   |

## 批次明细

至少 1 批、最多 30 批，新增空批次时产生稳定 lotId。原单商品次序不作为校验条件，交付按当前表单显示顺序。

| 字段         | 交付键             | 必填         | 输入与存值                                               |
| ------------ | ------------------ | ------------ | -------------------------------------------------------- |
| 货品编码     | `productCode`      | 是           | 3–32 个字符。                                            |
| 送货批号     | `lotCode`          | 是           | 2–32 个字符。                                            |
| 保管类型     | `storage`          | 是           | 常温（`ambient`）、冷藏（`chilled`）、冷冻（`frozen`）。 |
| 实收箱数     | `received`         | 是           | 1–5000 的整数，单位为箱。                                |
| 外观破损箱数 | `damaged`          | 是           | 0–5000 的整数，单位为箱。                                |
| 箱内抽测温度 | `temperatureDeciC` | 按规则或选填 | -500–800 的整数，单位为十分之一摄氏度。                  |
| 隔离记录     | `isolationNote`    | 按规则或选填 | 10–180 个字符。                                          |
| 破损说明     | `damageNote`       | 按规则或选填 | 8–180 个字符。                                           |

## 数量与重复批次

外观破损箱数不能超过该批实收箱数。破损大于 0 时说明必填，调回 0 后清除破损说明。按去空白、转大写的货品编码和批号的组合查重；同一货品不同批号可录入，同批号不同货品也可录入。冲突错误都绑定到对应批次的批号字段。

## 测温、隔离与清除

冷藏批次在 0.0–8.0 ℃（含端点）视为合格，超出要填写隔离记录。冷冻批次测温恰好 −18.0 ℃ 视为合格，高于 −18.0 ℃ 须隔离。测温录入整数，比如 −18.0 ℃ 填 −180。常温类型隐藏并清除测温字段。只在冷链超限时显示并要求隔离记录；纠正温度或改回常温时清除隔离记录。切换冷藏和冷冻时保留实测温度，按新阈值重新判断。破损说明保留独立。

## 仓库交付

完整校验后，Host 将货品编码和批号去空白并转大写，并按实际测温判定是否待隔离。交付每批的稳定标识、实收箱数、破损箱数、是否隔离和当前适用资料。允许记录并送交隔离批次，须把该批明确标为待隔离，供库存系统阻止入可用库位。发送失败时保留已填内容，相同提交键可以重试，防止重复创建收货记录。

## 验收场景

1. 同一车填写常温两箱、冷藏三箱和冷冻六箱，冷藏填 80、冷冻填 −180 时，两行均不需要隔离记录。
2. 冷冻改为 −179，出现隔离记录。补齐后仍可交付，但这批被标为待隔离，常温和冷藏批次保持各自状态。
3. 将冷冻行改为常温，测温和隔离记录消失。若这行已登记破损，破损说明保持。
4. 重复录入同一货品和批号，错误归到两行。删除一个中间批次后，其他批次的错误仍对应原批次。
5. 录入实收 7、破损 8 阻止交付，改为 7 后须补破损说明；改 0 后说明清除。
