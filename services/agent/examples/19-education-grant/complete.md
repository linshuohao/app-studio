# 学校学生资助批次申请

学校每学期集中向资助项目提交一批学生申请。同一学生可以申请不同类别，但每类别只允许一行。录入人员可以核对本批填写的申请，真实资格由学校后续审批。此样例到下发可审核的批次为止，交付单位统一为人民币分。

## 批次设置

学校和学期确定本批归属，预算适用整批。项目联系人接收校内退回通知。

| 字段                         | 交付键         | 必填 | 输入与存值                           |
| ---------------------------- | -------------- | ---- | ------------------------------------ |
| 学校名称                     | `school`       | 是   | 2–80 个字符。                        |
| 资助批次号                   | `programNo`    | 是   | 4–30 个字符。                        |
| 申请学期                     | `term`         | 是   | 春季（`spring`）、秋季（`autumn`）。 |
| 项目联系人                   | `coordinator`  | 是   | 2–40 个字符。                        |
| 联系人邮箱                   | `contactEmail` | 是   | 邮箱格式，按字符串交付。             |
| 本批预算                     | `budgetMinor`  | 是   | 100–100000000 的整数，单位为分。     |
| 已核对申请资料并获得使用授权 | `confirmed`    | 是   | 布尔值，初始未勾选。提交时必须勾选。 |

## 学生申请

一个批次录入 1–25 行，可以重排。申请行 ID 由 Host 在新增时分配。任何空行都应参与校验，录入顺序用于交付展示。

| 字段         | 交付键           | 必填         | 输入与存值                                                                     |
| ------------ | ---------------- | ------------ | ------------------------------------------------------------------------------ |
| 学籍编号     | `studentNo`      | 是           | 4–30 个字符。                                                                  |
| 学生姓名     | `studentName`    | 是           | 2–40 个字符。                                                                  |
| 补助类别     | `kind`           | 是           | 交通补助（`transport`）、学习用品补助（`materials`）、住宿补助（`boarding`）。 |
| 申请金额     | `requestedMinor` | 是           | 1–500000 的整数，单位为分。                                                    |
| 证明编号     | `evidenceNo`     | 是           | 4–32 个字符。                                                                  |
| 住宿证明编号 | `residenceCode`  | 按规则或选填 | 4–32 个字符。                                                                  |
| 金额复核说明 | `appealReason`   | 按规则或选填 | 12–250 个字符。                                                                |

## 金额与复核

类别额度上限为交通 600 元、学习用品 1,000 元、住宿 3,000 元，等于上限可通过。金额一律按分录入，额度与预算不得互相替代。金额大于 200,000 分时触发人工复核说明，降到等于 200,000 分时清除旧说明。所有行金额合计不得超过本批预算，合计超限的错误定位到本批预算，并提示已填申请合计。

## 类别切换与唯一性

住宿补助必须填写住宿证明编号。切到交通或学习用品时清除住宿编号，通用证明编号和当前金额不变。改回后要求重新提供住宿证明。学籍编号按去首尾空白和忽略英文字母大小写识别。同一学生不同类别可并存，同一学生同类别的重复提示定位到每条涉事行的学籍编号。

## 交付与退回

批次编号、学校和学期组成下游业务键，上一批退回后允许修改本批并重送，同一个已受理版本不得重复派出。交付包含每行申请 ID、学籍编号、学生名字、类别、金额、证明编号和当前适用的补充说明。Host 记录批次业务键和提交回执。网络失败保留工作值，既有行不重新分配 ID。

## 验收场景

1. 交通申请 60,000 分通过，60,001 分错误定位在该行金额，即使预算仍足够也阻止提交。
2. 住宿填写 200,001 分后出现金额复核说明，降到 200,000 分清除复核说明，住宿证明仍保留。
3. 学籍编号 `ST-0082` 的住宿与交通两行允许并存。加入 `st-0082` 的第二个住宿申请，两个住宿行报错，交通行不受影响。
4. 将校内预算设为 300,000 分，三条分别符合类别上限但总额 320,000 分时，批次预算报错。减少一条金额后，原行 ID 与证明资料保留。
5. 提交时网络中断，工作值保留；按原提交键重试后只创建一个待审批批次。
