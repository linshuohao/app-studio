# 部门采购预算与比价送审

部门按成本中心整理一次采购。单据内物品可能是办公消耗品、固定设备或工时服务。申请送到采购组审核，系统不在此环节生成订单。预计金额按人民币分表示，提交人可以在草稿阶段暂时留空。

## 申请资料

部门、成本中心与申请人共同定位预算归属。普通为默认优先级。只有紧急时要求说明，并在降级后清除旧理由。

| 字段                     | 交付键            | 必填         | 输入与存值                                          |
| ------------------------ | ----------------- | ------------ | --------------------------------------------------- |
| 申请部门                 | `department`      | 是           | 2–60 个字符。                                       |
| 申请人                   | `requester`       | 是           | 2–40 个字符。                                       |
| 成本中心编号             | `costCenter`      | 是           | 3–24 个字符。                                       |
| 采购优先级               | `urgency`         | 是           | 普通（`normal`）、紧急（`urgent`）。默认 `normal`。 |
| 最迟需要日期             | `neededBy`        | 是           | 真实自然日，格式 YYYY-MM-DD。                       |
| 项目用途                 | `businessPurpose` | 是           | 12–240 个字符。                                     |
| 申请预算上限             | `budgetMinor`     | 是           | 100–200000000 的整数，单位为分。                    |
| 紧急采购理由             | `emergencyReason` | 按规则或选填 | 12–200 个字符。                                     |
| 确认在预算范围内发起审批 | `confirmed`       | 是           | 布尔值，初始未勾选。提交时必须勾选。                |

## 采购明细

一单至少一项、最多三十项。新增空行生成稳定 lineId。明细支持重排，金额和错误继续跟随原行。

| 字段         | 交付键           | 必填         | 输入与存值                                                               |
| ------------ | ---------------- | ------------ | ------------------------------------------------------------------------ |
| 采购物品编码 | `sku`            | 是           | 3–32 个字符。                                                            |
| 物品规格     | `description`    | 是           | 4–120 个字符。                                                           |
| 品类         | `category`       | 是           | 办公消耗品（`office`）、固定设备（`equipment`）、外部服务（`service`）。 |
| 数量         | `quantity`       | 是           | 1–1000 的整数。                                                          |
| 预算单价     | `unitPriceMinor` | 是           | 1–10000000 的整数，单位为分。                                            |
| 比价记录编号 | `comparisonNo`   | 按规则或选填 | 4–30 个字符。                                                            |
| 服务验收范围 | `serviceScope`   | 按规则或选填 | 12–200 个字符。                                                          |

## 行金额与规则

预计小计等于数量乘预算单价，实时只读显示人民币元。工作值和下游金额统一保留人民币分。一行预计小计达到 500,000 分时须填写比价记录编号，恰好达到门槛也需要。调低至门槛下面时删除旧比价编号。选择外部服务时须填服务验收范围；切到其他品类时清除该说明，比价编号独立适用。

## 整单校验与错误定位

采购项中物品编码不可重复，去首尾空白并忽略大小写。出现重复，错误在涉及各行的物品编码上展示。不把接近的物品名称判断为重复。按所有行小计求整单合计，合计小于或等于申请预算上限才能送审；超预算错误归到预算上限。最迟需要日期由申请人填写有效自然日，采购组交接时根据收到时间分派。

## 审核交接

提交只交付填写的主管归属、当前适用的紧急理由、最迟需要日期、每行稳定 ID、规格、金额和适用的比价及验收资料。Host 用经过完整校验的同一份快照重新计算小计与合计，并交采购组生成回执。提交失败保留工作值，工单具备幂等键，重复提交不产生新的审核单。

## 验收场景

1. 数量 5、单价 100,000 分，小计显示 5,000 元，比价编号必填。改为数量 4 后比价编号隐藏且清除。
2. 选择外部服务，填写服务验收范围后再改固定设备，范围字段清除。仍达到门槛时原比价编号保留。
3. 填入两条分别为 300,000 分的小计并设置 600,000 分预算，整单通过；将其中一条提高 1 分后预算项报错。
4. 历史物品号用小写导入，与新行的大写物品号重复时，报告两行。重排不丢失各行错误。
5. 选紧急时清空理由无法提交，补齐后降级为普通，送审数据省略紧急理由。
