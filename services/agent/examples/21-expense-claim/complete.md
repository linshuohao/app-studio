# 跨城市差旅费用报销

财务系统接收同一段出差的凭证清单。一张单只包含一个项目和一个报销人，至少一条费用项，最多 40 条。尚未支付的借款差额由结算系统处理，业务样例到提交待审核报销单为止。

## 出差与预借款

日期包含出差首尾日，连续不超过三十天。同日出差按一天。已领借款由财务确认后录入，没有填 0；申报金额和借款均以分交付。

| 字段                     | 交付键         | 必填         | 输入与存值                           |
| ------------------------ | -------------- | ------------ | ------------------------------------ |
| 报销人工号               | `employeeNo`   | 是           | 4–24 个字符。                        |
| 报销人姓名               | `employee`     | 是           | 2–40 个字符。                        |
| 项目编号                 | `project`      | 是           | 4–24 个字符。                        |
| 出差开始日               | `travelStart`  | 是           | 真实自然日，格式 YYYY-MM-DD。        |
| 出差结束日               | `travelEnd`    | 是           | 真实自然日，格式 YYYY-MM-DD。        |
| 已领借款                 | `advanceMinor` | 是           | 0–10000000 的整数，单位为分。        |
| 报销备注                 | `claimNote`    | 按规则或选填 | 0–200 个字符。                       |
| 确认费用真实且未重复报销 | `attested`     | 是           | 布尔值，初始未勾选。提交时必须勾选。 |

## 逐笔费用

每条费用使用稳定 expenseId。票据编号须从原票据录入。费用行的参考说明、时间错误和发票冲突继续跟随该行，允许重排。

| 字段       | 交付键          | 必填         | 输入与存值                                                            |
| ---------- | --------------- | ------------ | --------------------------------------------------------------------- |
| 费用类目   | `expenseType`   | 是           | 铁路（`rail`）、住宿（`hotel`）、误餐（`meal`）、市内交通（`taxi`）。 |
| 费用发生日 | `occurredOn`    | 是           | 真实自然日，格式 YYYY-MM-DD。                                         |
| 票面金额   | `grossMinor`    | 是           | 1–5000000 的整数，单位为分。                                          |
| 申报金额   | `claimMinor`    | 是           | 1–5000000 的整数，单位为分。                                          |
| 票据编号   | `invoiceId`     | 是           | 6–40 个字符。                                                         |
| 乘车起讫点 | `route`         | 按规则或选填 | 6–120 个字符。                                                        |
| 入住晚数   | `nights`        | 按规则或选填 | 1–30 的整数。                                                         |
| 超标准说明 | `exceptionNote` | 按规则或选填 | 12–180 个字符。                                                       |

## 日期和金额边界

费用发生日须在出差日期内，含首尾。日期跨度及开始/结束顺序由出差字段校验，明细日期错则定位到该费用行。申报金额必须小于或等于票面金额，财务可以就一张票只报其中一部分。

## 类目条件

住宿标准是每晚 45,000 分，超过标准时允许申请，但必须填写超标准说明。金额或夜数变化后立刻重验。金额回到标准内时清除超标准说明。住宿必填晚数，切换其他类目清除晚数和超标说明。市内交通必须填写起点和终点文字，换到其他类目时清除旧路线。通用发票字段不随类目清除。

## 发票唯一与交付

同一票据按去空白、转大写识别。本单出现重复，报错落到每条涉事票据编号。财务票据服务另检查已占用的票号，按原明细稳定 ID 返回冲突。超时不标记已通过，允许重试和更正。提交要以校验通过的同一快照重新确认票号仍可用并保留幂等键。

结算输入包含每条当前适用明细和申报总金额（分）、借款金额（分）及两者差额（分）。总金额是申报而非票面合计。差额可能为负，负数交付给财务代表待归还款。

## 验收场景

1. 出差日期为 6 月 1–3 日，6 月 3 日发生的费用通过，6 月 4 日报在该行日期。
2. 入住两晚申报 90,000 分可以交付。申报 90,001 分，出现超标准说明。在补充说明前不得提交，补充后可进入人工审核。
3. 把第二条已超标的住宿改为铁路，仅第二条的晚数和说明清除。第一条住宿仍显示之前的资料。
4. 票面 17100 分，申报 17101 分时拒绝；17100 分允许。全单申报 17100 分、借款 20000 分，交付差额为 −2900 分。
5. 两笔相同票号因格式差异重复，两个明细都提示。票据核查后立刻改号，旧票号返回的阻塞不应覆盖新号。
6. 财务服务返回该发票已报销，清单保留并且问题定位到票据编号，用户替换票号后可以重试。
