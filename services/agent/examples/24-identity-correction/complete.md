# 柜台双区身份更正

请根据以下 PRD 创建一张中文投保表单，生成候选供我预览试填。请查询已有协议、组件物料及 Host 能力。若某项能力尚未接入，请说明影响哪个环节，以及接入方需要提供什么。

## 一、投保场景

客户在出发前为自己和同行家人一次投保。每张投保单有一名投保人、1 至 6 名被保人。投保人本人必须参保，固定为第一名被保人。允许仅为本人投保。

页面依次展示「旅行计划」「投保人」「被保人名单」「投保确认」。编辑时允许暂时留空，提交时校验整单。错误提示应定位到具体人员和字段，保留已填资料。

## 二、旅行计划

| 字段       | 业务要求                                                                                              |
| ---------- | ----------------------------------------------------------------------------------------------------- |
| 目的地国家 | 必选一个。页面显示日本、泰国、新加坡，分别提交 JP、TH、SG。                                           |
| 起保日期   | 必填。以北京时间的填单日期为准，可选次日至第 90 天，包含两个边界。                                    |
| 终保日期   | 必填，允许与起保日期相同。保险期间按首尾自然日计算，最长 30 天。例如 6 月 1 日至 6 月 30 日可以投保。 |
| 保障计划   | 必选。基础版提交 basic，增强版提交 plus。本次登记仅记录所选计划。                                     |

修改行程后，重新检查保险期间和每人的护照有效期。

## 三、投保人

本期受理持中国大陆普通护照的客户。下列字段均为必填。

| 字段                   | 填写与校验规则                                                                                                          |
| ---------------------- | ----------------------------------------------------------------------------------------------------------------------- |
| 中文姓名               | 去除首尾空白后为 2 至 30 个字符。允许汉字和姓名间隔号 `·`，间隔号不能位于首尾或连续出现。                               |
| 护照英文姓、护照英文名 | 分开填写，每项 1 至 39 个字符。允许英文字母，单词间可有一个空格或连字符，首尾必须为字母。去除首尾空白并转成大写后提交。 |
| 出生日期               | 必须是真实日期，不能晚于填单当天。                                                                                      |
| 护照号码               | 本产品使用一个英文字母加八位数字。接受小写输入，去除首尾空白并转大写后校验、查重和提交。                                |
| 护照有效期至           | 必须是真实日期，且不得早于终保日期；等于终保日期可以投保。延长行程时重新检查。                                          |
| 联系手机               | 11 位数字，以 1 开头，第二位为 3 至 9。                                                                                 |
| 联系邮箱               | 去除首尾空白后满足邮箱格式，用于接收电子保单。                                                                          |

## 四、被保人名单

1. 首次打开页面即有一张「被保人 1 · 本人」卡片。本人固定在首位，不能删除，关系不能修改。
2. 可以逐名添加最多五名家人。每次新增一张空卡片；空卡片也要参与提交校验。满六人后不能继续添加，删除一名家人后恢复添加。
3. 每位家人必填与投保人的关系、中文姓名、护照英文姓和名、出生日期、护照号码及护照有效期。填写格式沿用投保人规则。家人无需填写联系手机和邮箱。
4. 关系可选「配偶」「子女」「父母」。整单最多一名配偶。成年子女也可选「子女」。
5. 按归一化后的护照号码对名单内所有人查重，包含本人。重复时指出哪两人冲突。姓名相同、护照号不同可以继续。投保人资料与名单第一人代表同一个人，查重时只计一次。
6. 删除家人时只移除该人的资料、错误和核保结果。其他人的资料不变。若原第三人有护照错误，删除第二人后，该错误仍跟随原第三人。

## 五、投保人与第一名被保人双向同步

投保人区与第一名被保人卡片都允许编辑以下六项：中文姓名、护照英文姓、护照英文名、出生日期、护照号码、护照有效期。

任一处完成编辑后，另一处立即显示相同值。清空也要同步，旧值不能自动回填。更新后重新检查受影响的规则，例如护照查重和护照有效期。联系手机和邮箱只属于投保人。

例如，客户在投保人区录入护照号后，能在本人卡片看到；随后在本人卡片改正最后一位数字，投保人区也随之更新，配偶和子女的护照号保持原值。最终提交同时包含投保人和被保人名单，投保人与第一人的六项身份字段必须一致。

## 柜台交接

客户须勾选「我已核对所有人员与行程资料」，默认未勾选。本地检查通过后交付行程、投保人和按页面顺序排列的名单。本阶段仅登记资料，Host 提供北京时间业务日期。
