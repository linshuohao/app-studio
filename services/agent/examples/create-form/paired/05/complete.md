# 旅险目的地登记

请生成柜台用的中文登记表。按以下顺序展示字段，各项均无默认值。

1. 联系人姓名 contactName 必填，录入文本，长度为 1 至 40 个字符。
2. 目的地国家 countryCode 必填，从中国、日本中单选，分别保存 CN、JP。
3. 选定国家后才显示选填的城市备注 cityNote，使用文本输入。
4. 每次更换国家时清空旧城市备注，将 cityNote 置为 null。
5. 另外提供选填的目的地城市 city。选定国家后按国家和关键词远程搜索，显示名称，完整保存选项对象（id 为编码、label 为名称）。使用已有 travel.searchCities；换国家时将旧 city 置为 null。
