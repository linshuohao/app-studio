# 门店回访任务派单

## 业务场景

值班主管在交班前把已有回访任务分派给一名当班顾问。一个任务填一张派单，任务编号由主管从交班清单抄录。

## 录入与交付

按顺序填写任务号 taskNo（必填，RC 加 8 位数字）、承接顾问、优先级 priority（普通 normal 或紧急 urgent，默认普通）和交接说明 note（选填，最多 200 字）。承接顾问必选一人。所有字段独立。
门店目录由 Host 根据当前门店和登录身份查询。输入姓名或工号发起搜索，结果包含员工编号、姓名和工号；列表显示姓名和工号以区分重名。目录服务负责过滤停用人员。交班文件中承接顾问的存储口径见派单导入模板，此次材料未附该模板。
查询失败显示重试入口，保留已填资料；无结果时可修改关键词。仅从返回的候选中选择。

## 验收

用同一姓名查到两位顾问时可以按工号选中第二位。查询失败后重试成功，任务号和优先级保持原值。
