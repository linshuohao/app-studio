# 家庭投保渠道名单初核

请根据以下 PRD 创建一张中文投保表单，生成候选供我预览试填。请查询已有协议、组件物料及 Host 能力。若某项能力尚未接入，请说明影响哪个环节，以及接入方需要提供什么。

## 一、投保场景

客户在出发前为自己和同行家人一次投保。每张投保单有一名投保人、1 至 6 名被保人。投保人本人必须参保，固定为第一名被保人。允许仅为本人投保。

页面依次展示「旅行计划」「投保人」「被保人名单」「投保确认」。编辑时允许暂时留空，提交时校验整单。错误提示应定位到具体人员和字段，保留已填资料。

## 二、旅行计划

| 字段       | 业务要求                                                                                                                      |
| ---------- | ----------------------------------------------------------------------------------------------------------------------------- |
| 目的地国家 | 必选一个。页面显示日本、泰国、新加坡，分别提交 JP、TH、SG。                                                                   |
| 起保日期   | 必填。以北京时间的填单日期为准，可选次日至第 90 天，包含两个边界。                                                            |
| 终保日期   | 必填，允许与起保日期相同。保险期间按首尾自然日计算，最长 30 天。例如 6 月 1 日至 6 月 30 日可以投保。                         |
| 保障计划   | 必选。基础版提交 basic，增强版提交 plus。基础版接受本产品承保范围内的全部年龄；增强版要求每一名被保人在起保日均未满 70 周岁。 |

修改起保日期后，重新检查保险期间、所有人员的年龄分类和计划资格。若当前计划不再适用，保留客户选择，指出发生冲突的人员，让客户决定如何修改。

## 三、投保人

本期受理持中国大陆普通护照的客户。投保人在起保日须已满 18 周岁且未满 81 周岁。下列字段均为必填。

| 字段                   | 填写与校验规则                                                                                                          |
| ---------------------- | ----------------------------------------------------------------------------------------------------------------------- |
| 中文姓名               | 去除首尾空白后为 2 至 30 个字符。允许汉字和姓名间隔号 `·`，间隔号不能位于首尾或连续出现。                               |
| 护照英文姓、护照英文名 | 分开填写，每项 1 至 39 个字符。允许英文字母，单词间可有一个空格或连字符，首尾必须为字母。去除首尾空白并转成大写后提交。 |
| 出生日期               | 必须是真实日期，不能晚于填单当天。另按起保日校验投保年龄。                                                              |
| 护照号码               | 本产品使用一个英文字母加八位数字。接受小写输入，去除首尾空白并转大写后校验、查重和提交。                                |
| 护照有效期至           | 必须是真实日期，且不得早于终保日期；等于终保日期可以投保。延长行程时重新检查。                                          |
| 联系手机               | 11 位数字，以 1 开头，第二位为 3 至 9。                                                                                 |
| 联系邮箱               | 去除首尾空白后满足邮箱格式，用于接收电子保单。                                                                          |

## 四、被保人名单

1. 首次打开页面即有一张「被保人 1 · 本人」卡片。本人固定在首位，不能删除，关系不能修改。
2. 可以逐名添加最多五名家人。每次新增一张空卡片；空卡片也要参与提交校验。满六人后不能继续添加，删除一名家人后恢复添加。
3. 每位家人必填与投保人的关系、中文姓名、护照英文姓和名、出生日期、护照号码及护照有效期。填写格式沿用投保人规则，年龄资格按该人自己的出生日期计算。家人无需填写联系手机和邮箱。
4. 关系可选「配偶」「子女」「父母」。整单最多一名配偶。成年子女也可选「子女」。
5. 按归一化后的护照号码对名单内所有人查重，包含本人。重复时指出哪两人冲突。姓名相同、护照号不同可以继续。投保人资料与名单第一人代表同一个人，查重时只计一次。
6. 删除家人时只移除该人的资料、错误和核保结果。其他人的资料不变。若原第三人有护照错误，删除第二人后，该错误仍跟随原第三人。

## 五、投保人与第一名被保人双向同步

投保人区与第一名被保人卡片都允许编辑以下六项：中文姓名、护照英文姓、护照英文名、出生日期、护照号码、护照有效期。

任一处完成编辑后，另一处立即显示相同值。清空也要同步，旧值不能自动回填。更新后重新检查受影响的规则，例如护照查重、年龄分类、计划资格。联系手机和邮箱只属于投保人。

例如，客户在投保人区录入护照号后，能在本人卡片看到；随后在本人卡片改正最后一位数字，投保人区也随之更新，配偶和子女的护照号保持原值。最终提交同时包含投保人和被保人名单，投保人与第一人的六项身份字段必须一致。

## 六、年龄分类与附加资料

按起保日计算每个人的实足周岁。2 月 29 日出生的人，在非闰年按 2 月 28 日到达生日。分类由系统计算。

| 起保时年龄                   | 分类和处理                                                                                                                               |
| ---------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------- |
| 出生未满 30 个自然日         | 超出承保范围，指出该人并阻止提交。起保日与出生日正好相差 30 天可以承保。                                                                 |
| 出生已满 30 天、未满 18 周岁 | 归为未成年人，只接受与投保人关系为「子女」的人员。须在该人卡片勾选「我是其法定监护人」，默认未勾选。                                     |
| 已满 18、未满 70 周岁        | 归为成人，无需监护声明或高龄资料。                                                                                                       |
| 已满 70、未满 81 周岁        | 归为高龄，只能选基础版。须在该人卡片填写紧急联系人中文姓名和手机号，格式沿用投保人的中文姓名及手机号规则。投保人本人达到高龄时同样适用。 |
| 已满 81 周岁                 | 超出承保范围，指出该人并阻止提交。                                                                                                       |

修改起保日或生日后立即更新分类。某人从未成年变为成人时，保留原有关系并清除监护声明。从高龄变为成人时，清除该人的紧急联系人资料。再次进入原分类时须重新填写或勾选。其他人不受影响。

## 七、渠道名单初核

客户勾选「我已核对所有人员与行程资料」后，先完成本地检查，再发起渠道初核。送检计划、起终日期及每人稳定标识和归一化护照号，本人只计一次。发出请求后暂时锁定资料，到结果返回或超时才可继续编辑。渠道按人员标识返回通过或拒绝。拒绝时在对应卡片展示渠道原因，保留资料；改好后须重新送检。渠道可能漏回某个人。部分回包能否完成初核，运营口径待补；超时保留资料并允许重试。仅当全员通过时交付本次名单初核结果，后续投保由柜台另行办理。
